# Sprache

Sprache는 한국어 사용자를 위한 Android·Windows 공용 다국어 반복학습 앱입니다. 영어, 일본어, 독일어, 프랑스어, 스페인어, 중국어 간체를 지원합니다.

초기 명세를 기준으로 유지하는 장기 제품 목표와 다음 우선순위는 [`docs/product-goals.md`](docs/product-goals.md)에 정리되어 있습니다.

## 구현된 핵심 경험

- 로그인 없이 여섯 언어의 내장 단어 480개·문장 120개를 바로 학습
- 단어·문장 카드 학습, 뜻 고르기, 직접 쓰기, 빈칸, 문장 순서, 듣고 쓰기
- 목표 발음 TTS와 마이크 음성 인식을 결합한 발음 따라하기
- 간격 반복, 오답 재출제, XP·레벨·연속 학습·배지
- 일본어 가나·로마자와 중국어 병음 읽기 보조
- Android 게임형 UI와 Windows 크기 조절형 업무 도구 UI
- SQLite 기반 Local-First 저장과 CSV·JSON·JSONL 가져오기
- Google Drive 폴더를 원본 저장소로 사용하는 기기 간 동기화
- Railway API에는 HMAC 처리된 계정과 Drive 폴더 연결만 저장

- 최초 문제 묶음으로 다시 시작, 지금까지 틀린 문제만 집중, 남은 문제만 새 세션으로 분기
- 최초 세션·부모 세션·분기 단계와 시작·멈춤·재개·재시작 이력을 최대 50개까지 보존

## 1.14.0 안전한 콘텐츠 가져오기 검토

- CSV·JSON·JSONL의 각 행을 신규·동일·변경·차단으로 분류하고 원본 행 번호를 유지
- 뜻·허용 정답·읽기·문장 토큰·품사·태그·레벨·출처 등 변경 필드를 기존 값과 가져올 값으로 비교
- 신규 항목 포함·제외와 변경 항목 유지·교체를 항목별 또는 일괄로 선택
- 내장 콘텐츠 덮어쓰기와 ID·의미가 서로 다른 항목을 가리키는 모호한 충돌을 자동 차단
- 검토 뒤 기존 항목이 바뀌면 서명 재검사로 오래된 교체 요청을 거부
- 사용자 항목 교체 시 기존 ID와 학습 연결을 유지하고 콘텐츠 버전을 자동 증가
- 항목·삭제 tombstone·가져오기 이력을 하나의 SQLite transaction으로 저장
- SHA-256으로 같은 파일의 이전 가져오기 기록을 찾아 중복 작업을 사전에 안내
- 대용량 파일은 50개씩 나눠 표시하고 신규·변경·문제·선택 항목 필터 제공
- Android 라이트·다크와 Windows 비교 화면을 골든 이미지로 회귀 검증

## 1.13.0 나에게 맞추는 학습 세션

- 콘텐츠 레벨과 복수 태그, 단어·문장 포함 여부, 문장 비율, 5~30문제 세션 길이 조합

- Android 라이트·다크와 Windows 2열 업무형 화면, 375~1024px 반응형 검증

## 1.12.0 믿고 쌓을 수 있는 단어 데이터

- 단어마다 명사·동사·형용사 등 15개 품사를 저장하고 편집·검색·상세 화면에서 확인
- 사용자 직접 입력, 가져오기, SQLite, Drive snapshot 사이에서 출처·라이선스·원본 버전·콘텐츠 버전을 보존
- 같은 철자와 뜻이어도 품사가 다르면 별도 표현으로, ID만 다른 동일 표현은 중복 후보로 판정
- 가져오기 충돌 시 기존 ID와 학습 기록을 유지하면서 명시적으로 콘텐츠만 교체

## 1.11.0 끊겨도 남는 동기화와 Drive 무결성

- 모든 로컬 학습 변경을 최신 snapshot 한 건으로 합쳐 SQLite 업로드 대기 큐에 저장
- 앱을 종료했다 다시 열어도 payload·재시도 횟수·다음 재시도 시각을 복원
- 네트워크 실패 시 5초부터 최대 5분까지 백오프하고 수동 동기화 성공 시 정확한 작업만 제거
- 업로드 도중 더 새 로컬 변경이 생기면 이전 작업 완료가 새 작업을 지우지 않도록 operation ID로 보호
- Drive 다운로드를 `manifest → fileId → revision → SHA-256 → JSON` 순서로 검증
- pull 이후 다른 기기가 먼저 쓴 manifest 지문을 감지해 덮어쓰기 전에 다시 병합
- 설정 화면에 업로드 대기·재시도 횟수·다음 시각을 표시하고 재시작 후에는 실제 재연결 동작 제공

## 1.10.0 콘텐츠 신뢰성과 안전한 동기화

- 여섯 언어 공통 NFKC 정규화, 필수 필드, 길이, 우선순위, 학습 방식과 문장 토큰 정합성 검사
- 내장 단어 480개·문장 120개 전체를 공통 검증기로 자동 검사
- 중국어 `reading`을 병음으로 저장하고 언어에 맞지 않는 가나·로마자·병음 조합 차단
- 일본어 사용자 표현의 가나와 로마자를 분리 편집해 읽기 정보 손실 방지
- 가져오기에서 기존 항목 유지 또는 명시적 교체를 선택하고 저장 직전 다시 검증
- 손상된 Drive snapshot은 한 건도 로컬에 반영하지 않고 정상 로컬 데이터 유지
- 사용자 표현의 `updatedAt` 충돌 해결과 삭제 tombstone으로 다른 기기의 재생성 방지
- 앱 백그라운드 전환 직전 동기화와 장시간 이탈 후 복귀 동기화
- 날짜 의존 학습 큐의 시각 회귀 테스트를 고정 시계로 안정화

- 단어·문장 직접 추가·수정·삭제와 CSV·JSON·JSONL 일괄 가져오기
- 코스 범위·정확도·학습 단계·최근 세션을 보여주는 학습 리포트
- 설정·진도·사용자 표현·최근 세션을 포함한 JSON 백업 내보내기
- Drive 저장 범위와 Railway 개인정보 경계를 설명하는 설정 화면

## 바로 실행하기

로컬 `artifacts` 폴더에 기능 확인용 Mock 빌드가 있다.

- Windows: `Sprache-Windows-1.15.0-mock-x64.zip`을 풀고 폴더 안의 `sprache.exe`를 실행한다. DLL과 `data` 폴더를 EXE와 함께 유지해야 한다.
- Android: `Sprache-Android-1.15.0-mock-debug-signed.apk`를 테스트 기기에 직접 설치한다. 현재 APK는 Play Store 배포용 서명이 아니다.
- 무결성: `artifacts/SHA256SUMS.txt`의 SHA-256과 비교한다.

Mock 빌드는 Google 자격증명 없이 전체 학습 흐름을 시험하기 위한 것이다. 실제 Google 로그인·Drive 동기화를 사용하려면 `ENABLE_MOCK_MODE=false`와 플랫폼별 OAuth 설정이 필요하다.

## 개발 실행

Flutter 3.44.8, Node.js 22 이상, JDK 17을 기준으로 검증했다. Windows 빌드에는 Visual Studio 2022 C++ Desktop workload, Android 빌드에는 Android SDK가 필요하다.

```powershell
npm install
npm run dev:api
npm run run:client -- --dart-define=ENABLE_MOCK_MODE=true
```

```powershell
npm run lint:api
npm run test:api
npm run build:api
npm run analyze:client
npm run test:client
```
