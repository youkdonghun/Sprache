# Sprache 1.38.7

## 실제 GitHub 언어팩

- 빈 카탈로그를 끝내고 TUFS Open Language Resources의 CC BY 4.0 다국어
  기초 어휘를 한국어와 여섯 학습 언어의 공통 개념 ID로 대조해 팩 6개를 등록했다.
- 앱 내장 어휘와 팩 내부 중복을 생성 단계에서 제외했다. 실제 추가 항목은 영어
  352, 일본어 402, 독일어 361, 프랑스어 360, 스페인어 354, 중국어 370개다.
- 중국어 표기와 병음을 분리 보존하고, 한국어 뜻의 쉼표 구분 표현은 허용 답으로
  함께 저장한다.
- 팩 JSON은 Git 저장소에서 직접 받고 크기·SHA-256·언어·ID·버전·라이선스·
  항목 수를 확인한 뒤에만 가져오기 검토 화면으로 넘긴다.
- `language-packs/sources/`에 출처 정렬 자료와 내장 중복 제외 목록을 보존하고,
  `tool/refresh-language-packs.mjs`로 같은 팩을 재현한다.

## 조용한 Google Drive 동기화

- 백그라운드 저장, 앱 복귀, 예약 재시도와 자동 동기화는 상태 배너·오류 배너·
  완료 스낵바를 표시하지 않는다.
- Google 로그인·연결과 사용자가 직접 누른 `지금 동기화`만 진행 상태와 결과를
  표시한다.
- 학습 완료 화면은 Drive 대기 건수를 노출하지 않고 로컬 저장 완료만 간단히
  확인시킨다. 동기화 진단과 이력은 설정에서 사용자가 열었을 때 그대로 제공한다.
