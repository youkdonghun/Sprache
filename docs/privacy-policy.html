Sprache 개인정보처리방침

시행일: 2026년 7월 28일 · 대상 버전: 1.19.3

Sprache는 Android와 Windows에서 동작하는 Local-First 학습 앱입니다. Google 연결은 선택 사항이며, 로그인하지 않아도 로컬 학습을 사용할 수 있습니다.

Sprache는 광고나 데이터 판매를 하지 않으며, 학습 내용·답안·상세 진도를 Railway 데이터베이스에 저장하지 않습니다.

1. 처리하는 정보

  • 기기 로컬 데이터: 사용자가 만든 단어·문장·예문, 뜻, 읽기, 그룹, 일정, 가져오기 이력, 진도, XP, 오답, 최근 세션과 앱 설정
  • Google 기본 계정 정보: 로그인과 계정 선택에 필요한 Google 계정 식별자, 이메일, 기본 프로필 정보. Railway에는 이메일과 프로필을 저장하지 않습니다.
  • Google Drive 정보: 사용자가 Picker에서 선택한 폴더 ID·표시 이름과 Sprache가 만든 manifest·snapshot 파일의 ID, revision, checksum
  • Railway 계정 연결 정보: Google 계정 식별자를 서버 비밀값으로 HMAC-SHA256 처리한 키, Drive 폴더 ID·표시 이름, 스키마 버전, 생성·수정 시각
  • 운영 메타데이터: 호스팅 사업자가 보안과 서비스 운영을 위해 처리할 수 있는 IP 주소, 요청 시각, 경로, 응답 상태 같은 일반 네트워크 로그. 애플리케이션 로그에는 토큰과 인증 코드를 기록하지 않습니다.

2. Google 사용자 데이터 사용 목적과 범위

Sprache는 다음 최소 범위만 요청합니다.

  • openid, email, profile: 계정 확인과 로그인
  • https://www.googleapis.com/auth/drive.file: Sprache가 만들거나 사용자가 명시적으로 선택해 연결한 앱 파일을 저장·읽기·갱신

Google Drive 데이터는 Android와 Windows 사이에서 학습 내용을 이어 쓰고, 백업·복원하기 위해서만 사용합니다. 다른 Drive 문서를 읽거나 전체 Drive를 탐색하지 않습니다.

Sprache의 Google API 데이터 사용은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다.

3. 저장 위치와 보존

  • 학습 데이터는 먼저 기기의 SQLite 데이터베이스에 저장됩니다.
  • 사용자가 Google 연결을 켜면 검증된 snapshot이 선택한 Google Drive 폴더에 저장됩니다.
  • Windows OAuth 토큰은 운영체제 보안 저장소에 보관합니다. Android 토큰은 Google Identity 계층과 현재 연결 세션에서 처리합니다.
  • Railway의 계정–폴더 연결은 다른 기기와 재연결을 위해 유지되며, 사용자가 앱에서 계정–Drive 연결 기록 삭제를 확인하면 삭제됩니다.
  • 로컬 자료와 Drive 파일은 데이터 유실을 막기 위해 연결 해제만으로 자동 삭제하지 않습니다. 사용자가 앱, 운영체제 또는 Drive에서 직접 삭제할 때까지 유지됩니다.

4. 공유·이전·판매

Sprache는 Google 사용자 데이터와 학습 데이터를 광고, 판매 또는 사용자 프로파일링에 사용하지 않습니다. 다음 서비스는 요청된 기능을 제공하는 범위에서만 데이터를 처리합니다.

  • Google Identity, Picker, Drive: 로그인, 폴더 선택, 사용자가 선택한 파일 동기화
  • Railway: API와 PostgreSQL 호스팅, Windows Google 토큰 교환의 일시적 중계
  • 운영체제 음성 인식: 발음 연습의 마이크 입력 처리. 처리 방식은 사용자의 운영체제 및 음성 서비스 설정을 따릅니다.

법률상 의무가 있는 경우를 제외하고 위 목적 밖의 제3자에게 데이터를 공개하지 않습니다.

5. 발음 연습과 마이크

마이크는 사용자가 발음 연습을 시작할 때만 사용합니다. 음성 입력은 운영체제의 음성 인식 기능이 처리합니다. Sprache는 오디오 파일이나 인식된 문장을 Railway 또는 Drive에 저장하지 않고, 해당 학습 항목의 성공·재연습 결과만 일반 진도로 기록합니다.

6. 보호 조치

  • 공용 통신에 HTTPS 사용
  • Windows OAuth의 PKCE, 무작위 state와 로컬 loopback callback 검증
  • OAuth 토큰의 운영체제 보안 저장소 사용
  • Railway DB 계정 키의 HMAC-SHA256 비식별 처리
  • 토큰·인증 코드·PKCE verifier의 로그 제거와 응답 캐시 금지
  • Drive revision·SHA-256·스키마 검증 후에만 원격 데이터 병합

어떤 보안 방식도 절대적인 안전을 보장할 수는 없지만, 데이터 범위를 최소화하고 정상 로컬 데이터를 우선 보호합니다.

7. 사용자의 선택과 삭제

  • Google 연결을 사용하지 않고 로컬 모드로 계속 학습할 수 있습니다.
  • 이 기기에서 연결 해제를 선택하면 이 기기의 Google 토큰만 제거하고 다른 기기용 Railway 매핑은 유지합니다.
  • 계정–Drive 연결 기록 삭제를 확인하면 이 기기의 토큰과 Railway 계정–폴더 매핑을 함께 삭제합니다.
  • Google 계정의 보안 설정에서 Sprache의 접근 권한을 철회할 수 있습니다.
  • 사용자가 만든 학습 항목은 앱에서 삭제할 수 있습니다.
  • Drive에 남은 Sprache 폴더와 기기 앱 데이터는 사용자가 직접 삭제할 수 있습니다.

8. 정책 변경과 문의

데이터 처리 방식이 달라지면 이 문서의 시행일과 내용을 갱신하고, 중요한 변경은 앱 또는 공개 프로젝트 페이지에서 알립니다.

개인정보 및 데이터 처리 문의: github.com/youkdonghun/Sprache/issues

English summary

Sprache is a local-first study app for Android and Windows. Google connection is optional. The app uses basic Google identity scopes for sign-in and the narrow drive.file scope only to synchronize files created by Sprache or explicitly selected by the user.

Study content and detailed progress are stored locally and, when enabled, in the user's selected Google Drive folder. Railway stores only an HMAC-SHA256 account key and the selected Drive folder binding. It does not persist email, profile data, study content, answers, detailed progress, authorization codes, or OAuth tokens.

Sprache does not sell data, serve ads, or use Google user data for profiling. Platform speech recognition processes microphone input for pronunciation practice; Sprache does not persist audio or recognized transcripts. Users may disconnect Google in the app, revoke access in their Google Account, delete their own study items, and delete the Sprache folder from Drive.
