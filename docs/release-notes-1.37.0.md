# Sprache 1.37.0

## 전 플랫폼 저장 상태

- Windows, Android, iPhone PWA에서 `기기에 저장됨`, `Drive 대기`, `Drive 저장 중`, `재시도 필요`를 구분해 표시합니다.
- 앱을 잠깐 닫거나 다른 앱으로 전환해도 로컬 저장을 먼저 마친 뒤 가능한 시점에 Drive 동기화를 이어갑니다.

## 기본 자료 원본 비교·복구

- 앱 기본 단어와 문장을 편집할 때 원본 뜻, 발음, 예문을 함께 확인할 수 있습니다.
- `내 편집본`을 기본 원본으로 되돌려도 학습 기록과 즐겨찾기는 유지됩니다.
- 원본 복구는 Drive 삭제 표식으로 동기화되어 다른 기기에도 같은 결과가 적용됩니다.

## 플랫폼별 일괄 수정

- Windows Excel형 표에는 편집본 행마다 원본 복구 버튼을 제공합니다.
- Android와 iPhone PWA 카드형 편집 화면에는 원본 요약과 큰 복구 버튼을 제공합니다.
- 여러 수정과 원본 복구를 한 번의 로컬 트랜잭션과 한 번의 Drive 동기화 작업으로 처리합니다.

## 안정성

- 사용자 편집본과 기본 자료가 같은 ID로 중복 표시되지 않도록 유지합니다.
- 원본 복구 후 앱을 재실행해도 기본 자료가 그대로 복원되는 회귀 테스트를 추가했습니다.
