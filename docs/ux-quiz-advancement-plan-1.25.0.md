# Sprache 화면·학습·퀴즈 고도화 계획

버전 목표: `1.25.0`

핵심 목표는 기능 수를 늘리는 것이 아니라 사용자가 `오늘 무엇을 할지`, `어디서 자료를 관리하는지`, `문제를 왜 틀렸는지`, `다음에는 무엇을 해야 하는지`를 한 번에 이해하게 만드는 것이다.

## 공통 완료 기준

- Android 320/390/430px와 Windows 420/760/1280px에서 주요 기능을 사용할 수 있다.
- 라이트·다크 테마, 글자 배율 1.0/1.3/2.0에서 핵심 문구와 조작이 잘리지 않는다.
- 주요 터치 대상은 최소 44×44px이며 키보드만으로도 완료할 수 있다.
- 진행률과 정답 피드백은 화면뿐 아니라 스크린리더에도 의미가 전달된다.
- 새 로직에는 단위 또는 위젯 테스트가 있고 전체 정적 분석과 테스트를 통과한다.

## Phase A — 구조와 기준

- [x] Step 1. 오늘·학습·자료실·기록·설정과 실제 문제풀이 경로를 전수 조사한다.
- [x] Step 2. Android/Windows, 화면 폭, 테마, 글자 배율별 검증 행렬을 정한다.
- [x] Step 3. 중복 진입, 상태 소실, 접근성, 퀴즈 효용 문제를 P0/P1/P2로 분류한다.
- [x] Step 4. 46단계 로드맵과 단계별 완료 조건을 문서화한다.
- [x] Step 5. 현재 핵심 테스트와 정적 분석을 실행해 변경 전 기준선을 저장한다.

## Phase B — 전역 탐색과 화면 구조

- [x] Step 6. 상위 탭을 상태 보존형 구조로 바꿔 검색어·필터·스크롤·펼침 상태를 유지한다.
- [x] Step 7. 실제 문제풀이 화면에서는 하단 탭과 사이드바를 숨겨 이탈 실수를 막는다.
- [x] Step 8. Android와 Windows의 탭 이름을 `오늘·학습·자료실·기록·설정`으로 통일한다.
- [x] Step 9. 저장 상태를 `Drive 저장 중·로컬 저장 중·저장 위치 필요·저장 확인 필요`로 정확히 표시한다.
- [x] Step 10. 모든 상위 화면에서 현재 주제를 확인하고 바로 바꿀 수 있게 한다.
- [x] Step 11. 주제 레일의 순서를 고정하고 선택 후 위치·키보드 초점이 흔들리지 않게 한다.
- [x] Step 12. 주제 레일 화살표를 44px 이상으로 키우고 Arrow/Home/End 키 탐색을 제공한다.

## Phase C — 학습실 진입 경험

- [x] Step 13. 학습실의 동일 경로 중복 버튼을 제거하고 추천 행동을 하나로 명확히 한다.
- [x] Step 14. 기본 화면에는 `추천 1개 + 빠른 연습 3개`만 노출하고 전체 방식은 한곳에서 펼친다.
- [x] Step 15. 학습 방식 카드를 `<520 1열·520~899 2열·900 이상 3열`로 반응형화한다.
- [x] Step 16. 퀴즈 시작 전 문제 유형·대상·예상 시간·문제 수를 보여주는 시작 패널을 추가한다.
- [x] Step 17. 시작 패널에서 5·10·20문제를 한 번에 선택할 수 있게 한다.
- [x] Step 18. 선택한 방식에 사용할 자료가 없을 때 이유와 해결 행동을 함께 보여준다.
- [ ] Step 19. 최근 사용 방식과 사용자가 고정한 방식을 빠른 연습에 반영할 기반을 만든다.

## Phase D — 퀴즈 큐와 문제 품질

- [x] Step 20. 퀴즈 실행마다 문제 수를 지정할 수 있도록 큐에 세션 한정 개수 옵션을 추가한다.
- [x] Step 21. 선택지 후보를 자료 유형·언어·난이도·길이·태그 유사도로 선별한다.
- [x] Step 22. 중복 선택지와 정답과 사실상 같은 선택지를 제거한다.
- [x] Step 23. 단어·문장별로 단계형 힌트를 제공하고 힌트를 쓸수록 점수를 조정한다.
- [x] Step 24. `모르겠어요`를 제공해 임의 오답을 누르지 않고 정답을 학습하게 한다.
- [x] Step 25. 문장 배열에 `한 칸 되돌리기·처음부터`를 추가한다.
- [x] Step 26. 듣기 문제에 `다시 듣기·느리게 듣기`와 재생 횟수 안내를 추가한다.
- [ ] Step 27. 취약·즐겨찾기·마감 복습 방식에서도 문제 유형과 자료 선별 규칙이 일관되게 동작하게 한다.

## Phase E — 피드백과 학습 루프

- [x] Step 28. 정답 팝업에 내 답·정답·뜻·읽기 표기를 구분해 보여준다.
- [x] Step 29. 오답 팝업에 틀린 이유와 다음 복습 반영 여부를 짧게 설명한다.
- [x] Step 30. 피드백에서 발음을 바로 다시 듣고 즐겨찾기를 바꿀 수 있게 한다.
- [x] Step 31. 틀린 문제는 세션 안에서 한 번 다시 나오고 완료 화면에서 별도 재도전할 수 있게 한다.
- [x] Step 32. 헤더에 남은 문제·정답·오답·예상 남은 시간을 간결하게 표시한다.
- [x] Step 33. 완료 화면의 다음 행동을 `오답 재도전·다음 추천·학습실` 순으로 상황에 맞게 제시한다.
- [ ] Step 34. 키보드 단축키와 화면 버튼의 동작·도움말·초점 순서를 일치시킨다.

## Phase F — 접근성과 집중도

- [ ] Step 35. 문제 변경·힌트·정오답·미션 완료를 live region으로 안내하고 초점을 복원한다.
- [x] Step 36. 진행률에 `영어 복습 3/10`처럼 문맥 있는 스크린리더 레이블을 제공한다.
- [ ] Step 37. 시스템의 동작 줄이기 설정에서 콤보·테마·레일 스크롤 애니메이션을 제거한다.
- [x] Step 38. 통계 히어로의 글자 대비를 일반 텍스트 4.5:1 이상으로 보정한다.
- [x] Step 39. Windows 사이드바에 현재 위치 의미와 본문 바로가기 키보드 동작을 추가한다.

## Phase G — 홈·자료실·기록·설정·미션

- [x] Step 40. 홈 첫 화면을 `이어하기·마감 복습·다음 학습` 중 하나의 주 행동 중심으로 재배치한다.
- [x] Step 41. 설정의 기본 시작 모드와 홈 주 버튼의 실제 동작을 일치시킨다.
- [x] Step 42. 모바일 자료실 상단을 축약해 320px에서도 실제 자료 행이 먼저 보이게 한다.
- [ ] Step 43. Windows 자료실을 목록–상세 2단 구조로 바꾼다.
- [ ] Step 44. 기록 화면에서 복습 행동을 수치보다 먼저 제시하고 단계별 자료로 이동하게 한다.
- [ ] Step 45. 설정을 모바일 접이식 섹션, Windows 목록–상세 구조로 정리한다.
- [ ] Step 46. 실전 미션 중단 지점과 기억도 평가를 저장해 복습 큐에 반영한다.

## Phase H — 적응형 학습 데이터

- [ ] Step 47. 한 항목의 뜻 고르기·쓰기·듣기·발음 숙련도를 분리해 쉬운 객관식이 전체 숙련도를 대신하지 않게 한다.
- [ ] Step 48. 혼합 학습을 고정 순환 대신 최근 오답 유형·응답 시간·능력별 숙련도 기반 적응형 출제로 바꾼다.
- [ ] Step 49. 여섯 언어의 표기 규칙과 콘텐츠가 허용한 외국어 대체 정답을 정답 정책에 반영한다.
- [x] Step 50. 오답을 한 번만 다시 내는 대신 연속 회상 성공 또는 안전한 시도 상한까지 이어지는 보정 루프를 적용한다.
- [ ] Step 51. 발음 점수와 일반 암기 숙련도를 분리하고 수동 완료는 무채점 연습으로 기록한다.
- [ ] Step 52. 실전 미션을 상황 제시·상대 발화·응답·결과 분기가 있는 실제 상호작용 흐름으로 확장한다.
