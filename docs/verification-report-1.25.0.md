# Sprache 1.25.0 UX·퀴즈 고도화 검증 보고서

검증일: 2026-07-30

## 구현 범위

- 상위 탭을 상태 보존형 라우팅으로 바꾸고 실제 문제풀이는 탭과 사이드바가
  없는 집중 화면으로 분리했다.
- Android와 Windows의 탐색 이름, 현재 주제, 활성 저장 위치 표시를 통일했다.
- 주제 레일의 순서를 고정하고 44px 조작 영역, Arrow/Home/End 키 이동과
  글자 배율 대응 높이를 적용했다.
- 학습실의 중복 진입을 줄이고 빠른 연습 3개, 전체 방식 펼치기, 시작 전
  문제 수·예상 시간·사용 가능 자료 확인 패널을 추가했다.
- 세션별 5·10·20문제 선택, 유사도 기반 오답 보기, 단계형 힌트,
  `모르겠어요`, 문장 배열 되돌리기·초기화, 듣기 재생·느린 재생을 추가했다.
- 정오답 팝업에 내 답, 정답, 뜻, 읽기, 예문, 복습 반영 설명, 발음 재생과
  즐겨찾기를 모았다.
- 틀린 문제는 안전한 상한 안에서 다시 출제하고, 완료 화면은
  `오답 재도전 → 다음 추천 학습 → 학습실/코스` 순으로 정리했다.
- 영어·일본어·독일어·프랑스어·스페인어·중국어의 입력 정규화 규칙과
  스마트 선택지 생성 로직을 분리해 단위 테스트 가능하게 만들었다.
- 2.0배 글자, 라이트·다크, 시스템 동작 줄이기, 문맥 있는 진행률 의미,
  Windows `F6` 본문 이동을 보강했다.
- 미션 집중 화면의 누락된 배경과 Google 오류 스낵바가 진단 버튼을 덮는
  문제를 시각·위젯 검사에서 발견해 수정했다.

52단계 계획 중 이번 버전에 검증 완료한 단계는 38개이며, 남은 14개는
적응형 숙련도 데이터, 실제 분기형 미션, Windows 자료실·설정 2단 구조처럼
데이터 모델 또는 화면 구조 변경이 큰 후속 묶음이다.

## 남은 배포 위험

- Android APK는 직접 설치 테스트용 Debug 인증서다. Play 배포 전 release
  keystore와 그 SHA 지문을 Google OAuth Android 클라이언트에 등록해야 한다.
- Windows 실행 파일과 설치 관리자는 Authenticode 서명이 없다. 외부 배포 전
  코드 서명 인증서가 필요하다.
- 실제 Android 기기의 마이크·TTS·파일 선택기·SAF 권한과
  Android↔Windows Google Drive 교차 동기화는 물리 기기에서 최종 확인해야 한다.
- Flutter는 현재 Kotlin Gradle Plugin 방식이 향후 버전에서 제거될 예정이라고
  경고했다. 다음 Flutter 도구체인 업그레이드 전에 Built-in Kotlin 전환이
  필요하다.
