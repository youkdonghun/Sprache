# Sprache 1.39.2

## 발음 안정화

- 영어 철자를 한글로 기계 변환하던 경로를 차단해 `beef` 같은 단어에 잘못된 발음 보조표기가 붙지 않게 했습니다.
- 영어·일본어·독일어·프랑스어·스페인어·중국어는 각 코스의 전용 TTS 로캘로 재생합니다.
- 빠르게 여러 번 눌렀을 때 음성이 겹치지 않도록 기존 직렬 재생 보호를 전 언어 테스트로 검증했습니다.
- 내장 한글 발음 표기는 직접 검수한 값만 우선하고, 일본어 가나·로마자와 중국어 병음은 원문 읽기 자료로 함께 보존합니다.

## 영어 시험 언어팩

- `TOSS 기본 어휘 721`을 별도 언어팩으로 추가했습니다. 일상 회화 빈도가 높은 NGSL-Spoken 1.2를 기반으로 하며 공식 시험 문제집은 아닙니다.
- `TOEIC 기본 어휘 1,250`을 별도 언어팩으로 추가했습니다. TOEIC Service List 1.2의 표제어를 빠짐없이 수록했습니다.
- 두 팩은 앱의 `자료실 → 언어팩 받기`에서 서로 따로 설치할 수 있습니다.
- 뜻은 한국어로 정리했고, 영어 한글 발음을 추측 생성하지 않습니다. 발음 듣기는 기기의 영어 음성을 사용합니다.

## 검증

- 언어팩 원본 개수, 중복, 필수 필드, 한국어 뜻, 라이선스, 카탈로그 해시를 자동 검사합니다.
- Flutter 정적 분석, 전체 테스트, Windows·Android·PWA 빌드 결과를 확인한 뒤 배포합니다.
