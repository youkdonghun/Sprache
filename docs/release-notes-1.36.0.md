# Sprache 1.36.0 출시 안내

버전은 `1.36.0+61`입니다. 이번 버전은 단어를 많이 다루는 사용자가 더 빠르게 정리하고, 곧바로 원하는 방식으로 연습할 수 있도록 저장·가져오기·편집·퀴즈 흐름을 다듬었습니다.

## 주요 변경

- 영구 저장과 기기 간 동기화 경로를 Google Drive 중심으로 정리했습니다. 샘플 학습은 로그인 전에도 가능하며, 내 자료를 보관하려면 Google 연결을 안내합니다.
- PWA는 학습 중인 작업 사본을 브라우저 SQLite/IndexedDB에 보존하고 Google Drive를 기기 간 동기화·복구 원본으로 사용합니다.
- 한 번 승인한 Google 세션은 앱 재실행과 토큰 만료 때 조용히 복구합니다. 세션이 실제로 끊긴 경우에만 재연결을 안내하며, 일반 화면 이동이나 저장 때 로그인 창을 반복해서 열지 않습니다.
- PDF 가져오기를 Windows·Android·Web·Apple 공통 흐름으로 추가했습니다. 텍스트 PDF에서 단어와 뜻을 찾아 검토한 뒤 저장할 수 있습니다.
- PDF 원본은 자동 업로드하지 않습니다. 파일명, SHA-256, 페이지 번호와 짧은 문맥만 출처 정보로 보존합니다.
- 스캔 이미지 PDF는 OCR 미지원임을 명확히 알리고, 암호화 PDF는 현재 분석 세션에서만 비밀번호를 사용합니다.
- 단어 목록에서 여러 항목을 선택해 엑셀처럼 한 화면에서 표현, 뜻, 한국어 발음, 예문, 태그와 난이도를 일괄 수정할 수 있습니다.
- 일괄 편집 저장은 하나의 작업으로 처리해 일부 항목만 반영되는 상황을 막고, 저장 뒤 Google Drive 동기화 대기열에 한 번만 추가합니다.
- 사용자 지정 퀴즈 문항 수의 상한을 100개에서 1,000개로 늘렸습니다.
- 좁은 화면과 넓은 화면 모두에서 학습 허브, 자료실, 가져오기와 설정 화면의 밀도·탐색 동선을 다시 맞췄습니다.
- PWA의 오프라인 캐시와 새 버전 안내를 갱신했습니다.

## PDF 가져오기 범위

- 파일당 20MB, 최대 500페이지, 추출 본문 200만 자, 검토 후보 5,000개를 지원합니다.
- `단어 - 뜻`, `단어: 뜻`, 표 형태처럼 뜻이 명확한 항목만 기본 선택합니다.
- 일반 문서에서 찾은 단어 후보는 뜻을 직접 입력한 뒤 저장합니다.
- 이미지로만 된 스캔 PDF의 OCR, 외부 AI 뜻 생성, 자동 번역은 이번 버전에 포함하지 않습니다.

## 플랫폼 결과물 이름

- `Sprache-안드로이드용-1.36.0.apk`
- `Sprache-윈도우용-1.36.0.exe`
- `Sprache-맥용-1.36.0.zip`
- `Sprache-아이폰용-1.36.0.ipa` 또는 서명 방식에 맞는 iOS 패키지
- `Sprache-iPhone-PWA-바로가기.url`

Windows에서 직접 만들 수 없는 macOS·iOS 패키지는 Codemagic의 Apple 빌드 환경을 사용합니다. 실제 iPhone 설치 가능 여부는 Apple 서명 방식에 따라 달라집니다.
