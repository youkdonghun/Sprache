Sprache 소개 개인정보처리방침 문의

서비스 이용약관

시행일: 2026년 8월 3일

1. 서비스

Sprache는 사용자가 직접 학습 자료를 만들고 기기 로컬 저장소 또는 선택적으로 연결한 Google Drive에서 관리하도록 돕는 Android·Windows 학습 도구입니다.

2. 사용자 책임

사용자는 가져오거나 공유하는 학습 자료에 필요한 권리를 확보해야 하며, Google 계정과 기기의 접근 권한을 안전하게 관리해야 합니다. 타인의 권리 침해, 불법 콘텐츠 유통, 서비스나 외부 제공자에 대한 방해 행위에 앱을 사용해서는 안 됩니다.

3. 데이터와 선택적 Google 연결

Google 연결은 선택 사항입니다. 연결하면 동기화 자료는 사용자가 고른 Drive 위치의 WordStudyData에 저장되고, 숨겨진 앱 설정에는 그 폴더를 다시 찾기 위한 포인터만 저장됩니다. 연결하지 않아도 로컬 기능을 사용할 수 있습니다. 네트워크 또는 외부 서비스 장애가 발생해도 정상 로컬 자료를 우선 보존하도록 설계하지만, 중요한 자료는 정기적으로 내보내기·백업하는 것을 권장합니다.

4. 외부 서비스와 가용성

Google Identity, Google Drive, 운영체제 음성 서비스와 GitHub Pages에는 각 제공자의 약관과 운영 정책이 적용됩니다. Sprache는 외부 서비스의 중단, 계정 제한 또는 정책 변경을 통제할 수 없으며 특정 시점의 무중단 제공을 보장하지 않습니다.

5. 보증과 책임 범위

Sprache는 학습을 돕는 도구이며 시험 결과, 번역·발음의 완전한 정확성 또는 특정 학습 성과를 보장하지 않습니다. 관련 법률이 허용하는 범위에서, 사용자는 중요한 자료의 백업과 제출 전 검토에 대한 책임을 집니다.

6. 변경과 문의

기능 또는 데이터 처리 방식이 달라지면 약관과 개인정보처리방침을 갱신합니다. 문의는 Sprache 프로젝트 문의 페이지에서 접수합니다.
