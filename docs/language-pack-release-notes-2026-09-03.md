# 영어 시험 언어팩 2026.09.2

## 5,000개 전체판

- TOSS 팩을 말하기 고빈도 단어 4,750개와 회화·숙어 250개, 총 5,000개로 확장했다.
- TOEIC 팩을 시험·업무 고빈도 단어 4,750개와 실무 결합표현 250개, 총 5,000개로 확장했다.
- 기존 팩 ID와 초기 항목 ID를 유지하고 revision을 2로 올려 앱에서 업데이트로 표시한다.

## 뜻 품질과 재현성

- NGSL-Spoken·NGSL·NGSL-GR·TSL·BSL의 공개 목록을 용도에 맞게 조합했다.
- TUFS와 한국어 위키낱말사전을 우선 사용하고, 빈 항목만 공개 영한 사전으로 보완했다.
- `career=생애`, `competition=각축`, `component=거동하다`처럼 학습 문맥에
  맞지 않는 보조 사전 뜻을 별도 교정표로 바로잡았다.
- 모든 항목의 한국어 뜻, 고유 ID, 중복 표제어, 250개 표현 수, 라이선스와
  카탈로그 SHA-256을 자동 검사한다.
- 영어 철자에서 한글 발음을 추측하지 않으며 발음 듣기는 기존 영어 TTS를 사용한다.
