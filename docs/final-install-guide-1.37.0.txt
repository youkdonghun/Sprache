Sprache 1.37.0 설치 안내

[Windows]
1. Windows 폴더 전체를 같은 위치에 둡니다.
2. Sprache-윈도우용-1.37.0.exe를 실행합니다.
3. exe 옆의 data 폴더와 DLL 파일을 이동하거나 삭제하지 마세요.

[Android]
1. Sprache-안드로이드용-1.37.0.apk를 휴대폰으로 복사합니다.
2. APK를 열고, Android가 요청하면 이 파일을 설치할 권한을 한 번 허용합니다.
3. 기존 Sprache 위에 설치하면 학습 데이터가 유지됩니다.

[iPhone PWA]
1. Safari에서 https://sprache6.github.io/app/ 를 엽니다.
2. 공유 버튼을 누르고 '홈 화면에 추가'를 선택합니다.
3. '웹 앱으로 열기'를 켠 뒤 추가합니다.
4. 이후 홈 화면의 Sprache 아이콘으로 실행합니다.

[Google Drive]
- 처음 한 번 Google 계정과 Drive를 연결합니다.
- '기기에 저장됨 · Drive 대기'는 데이터가 먼저 안전하게 저장됐고 전송을 기다리는 상태입니다.
- '기기에 저장됨 · 재시도 필요'가 보이면 인터넷 연결 후 설정의 '지금 동기화'를 누릅니다.
