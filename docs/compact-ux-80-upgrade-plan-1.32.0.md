# Sprache 1.32.0 컴팩트 UX 80개 개선 목표

## 방향

이번 업그레이드는 기능을 무작정 늘리기보다 첫 화면의 선택 수, 반복 설명, 카드
높이, 이동 거리와 재설정 횟수를 줄인다. Duolingo의 단일 다음 학습과 Practice
Hub, Drops의 이어 하기와 짧은 세션, Busuu의 어휘 저장·검색·강도 복습,
Babbel의 복습 형식 선택, Anki의 화면 밀도와 점진 공개, LingQ의 이어 보기
중심 구조를 상호작용 원칙으로만 참고한다. 화면·문구·브랜드 자산은 복제하지
않는다.

완료 기준은 80개 항목 각각에 대응하는 프로덕션 코드와 회귀 테스트 또는 실제
화면 근거가 있고, 기존 Local-First 저장·동기화·접근성 동작을 깨뜨리지 않는
것이다.

## 1. 불필요한 잠금 제거와 용어 정리

- [x] 01. 백그라운드 전환 뒤 표시되던 Sprache 보호 중 커튼을 제거한다.
- [x] 02. 커튼 타이머·지연 enum·설정 필드를 제거하되 과거 curtainDelay JSON은 오류 없이 무시한다.
- [x] 03. 개인정보 가림, 알림 내용 표시, Drive 네트워크 차단을 앱 잠금과 혼동하지 않도록 설정 구조와 문구를 정리한다.

## 2. 전역 탐색과 홈 1차 압축

- [x] 04. 보통·컴팩트 밀도가 화면별 padding과 gap에도 적용되는 공통 레이아웃 토큰을 추가한다.
- [x] 05. 컴팩트 데스크톱 사이드바 너비를 줄이되 44px 조작 영역은 유지한다.
- [x] 06. 사이드바 항목과 보조 동작 사이의 반복 여백을 밀도 토큰으로 통일한다.
- [x] 07. 상단 학습 주제 바의 세로 높이와 불필요한 빈 공간을 줄인다.
- [x] 08. 홈 최상단에는 가장 중요한 이어 하기 동작 하나가 먼저 보이도록 한다.
- [x] 09. 오늘 할 일을 카드 나열 대신 한 줄 지표로 요약한다.
- [x] 10. 복습 예정 수가 0일 때 큰 빈 복습 카드를 노출하지 않는다.
- [x] 11. 주간 목표를 큰 카드 대신 진행 스트립으로 바꾼다.
- [x] 12. 홈의 보조 통계와 설명은 좁은 화면에서 자동 줄바꿈·축약한다.

## 3. 단어 등록과 자료실 1차 압축

- [x] 13. 빠른 등록을 열면 표현·뜻 두 필드가 다른 도구보다 먼저 보이게 한다.
- [x] 14. 읽기·예문·태그 등 선택 입력은 더 입력 영역에 접어 둔다.
- [x] 15. 마지막 언어·자료 종류·그룹 기본값을 재사용해 반복 선택을 줄인다.
- [x] 16. 등록 템플릿·바구니 도구는 요약 헤더 한 줄에서 펼쳐 쓰게 한다.
- [x] 17. 학습 그룹 검색·새 그룹 만들기는 필요할 때만 펼치게 한다.
- [x] 18. 빠른 등록 시트의 최대 너비·가장자리 여백·섹션 간격을 밀도에 맞춰 줄인다.
- [x] 19. 중복 감지는 입력 바로 아래의 짧은 상태로 먼저 알리고 상세 비교는 요청할 때 연다.
- [x] 20. 저장과 실행 취소를 입력 흐름 가까이에 유지해 스크롤 왕복을 줄인다.
- [x] 21. 자료실의 검색·강도·그룹 필터를 결과 바로 위 한 영역에 모은다.
- [x] 22. 자료 흐름과 스마트 컬렉션 안내는 압축 요약으로 시작하고 상세를 펼쳐 본다.

## 4. 퀴즈·게임·설정 1차 압축

- [x] 23. 학습 허브의 개인 추천을 100px 이내의 가로 행으로 압축한다.
- [x] 24. 실수·단어·듣기·말하기·게임 진입점을 한 연습 허브에서 빠르게 훑게 한다.
- [x] 25. 세션 시작 전 3·5·10·15분 프리셋을 한 줄로 제공한다.
- [x] 26. 시간 프리셋 옆에 예상 문제 수를 즉시 표시한다.
- [x] 27. 문제 수·난이도·형식은 기본 화면에 두고 순서·기록·세부 제한은 고급 설정으로 접는다.
- [x] 28. 최근 사용 모드와 즐겨찾기 모드를 다른 모드보다 앞에 배치한다.
- [x] 29. 설정의 테마·밀도·글자 크기 핵심 제어를 한 화면에서 비교하게 한다.
- [x] 30. 컴팩트 작업 공간 프리셋으로 밀도·탐색 레이블·홈 모듈을 한 번에 적용하고 되돌릴 수 있게 한다.

## 5. 홈과 전역 탐색 2차 압축

- [x] 31. 홈 바깥 여백을 화면 밀도와 플랫폼에 맞춰 축소한다.
- [x] 32. 모바일·컴팩트 홈 헤더를 짧은 제목과 한 줄 부제로 바꾼다.
- [x] 33. 홈 빠른 행동 세 개를 중첩 카드 대신 44px 단일 도구 띠로 합친다.
- [x] 34. 컴팩트 홈의 주 학습 카드 설명·XP 문구·간격을 축약한다.
- [x] 35. 주간 목표를 48px 요약 행으로 줄이고 좁은 화면의 반복 제목을 없앤다.
- [x] 36. 오늘 계획을 세 지표 한 줄로 유지하고 컴팩트 모드의 제목 행을 생략한다.
- [x] 37. 2분 복습을 한 줄 행동 행으로 바꾸고 알림·시작은 44px을 유지한다.
- [x] 38. 홈 각 섹션 사이 간격을 공통 밀도 토큰으로 통일한다.
- [x] 39. 최근 추가 자료는 최신 세 개만 보이고 전체 이동을 제공한다.
- [x] 40. 고정 컬렉션 헤더를 44px 관리 아이콘과 한 줄 칩 영역으로 축소한다.
- [x] 41. Windows 사이드바의 검색·추가·도움말을 한 줄 도구 모음으로 통합한다.
- [x] 42. 840px 미만 데스크톱 창은 하단 탐색으로 전환해 본문 폭을 확보한다.
- [x] 43. 사이드바 하단 주제와 저장 상태를 두 줄에서 한 줄로 합친다.
- [x] 44. 터치 기기에서는 키보드 도움말을 숨기고 상단 검색·빠른 추가를 44px 이상으로 복구한다.
- [x] 45. 컴팩트 모바일 하단 탐색 높이를 60px로 고정한다.
- [x] 46. 컴팩트 홈과 컴팩트 탐색 구성을 각각 한 번에 적용할 수 있게 한다.

## 6. 빠른 등록과 자료실 2차 압축

- [x] 47. 자료실에서 메뉴를 거치지 않고 단어 추가를 한 번에 연다.
- [x] 48. 컴팩트 밀도에서는 빠른 등록의 반복 설명을 숨겨 헤더를 한 줄 줄인다.
- [x] 49. 넓은 빠른 등록 모달에서는 표현과 뜻을 같은 행에 배치한다.
- [x] 50. 표현·뜻 즉시 지우기 버튼을 제공하되 키보드 포커스 순서는 방해하지 않는다.
- [x] 51. 필수 완료 상태를 작은 pill로 표시하고 큰 글자에서는 문구를 축약한다.
- [x] 52. 문자·공백 정규화 제안을 최대 한 줄로 줄이고 적용 동작은 유지한다.
- [x] 53. 중복 감지를 같은 표현·새 뜻 수의 한 줄 상태로 먼저 알린다.
- [x] 54. 기존·신규 자료 비교와 병합 필드 요약은 비교를 눌렀을 때만 펼친다.
- [x] 55. 병합·기존 열기·별도 저장은 바로 보이고 기본 중복 정책을 함께 표시한다.
- [x] 56. 최근 그룹을 한 번에 다시 선택할 수 있게 한다.
- [x] 57. 선택된 그룹은 그룹 목록을 펼치지 않고 헤더에서 바로 해제한다.
- [x] 58. 새 그룹 이름은 요청 후 표시하고 검색어를 이름 후보로 재사용한다.
- [x] 59. 추가 정보 헤더에 실제 입력된 선택 항목 수를 표시한다.
- [x] 60. 넓은 화면에서 예문 쌍과 즐겨찾기·우선순위 제어를 각각 한 행으로 묶는다.
- [x] 61. 데스크톱 하단 학습·바구니·계속 추가·저장 동작을 한 행으로 합친다.
- [x] 62. 자료실 검색 결과 수·필터별 수량·결과 학습 동작을 검색 문맥 안에 모은다.
- [x] 63. 모바일 그룹 도구를 세 행에서 두 행으로 줄이고 수선 알림·결과 행도 낮춘다.

## 7. 연습·게임·세션 2차 압축

- [x] 64. 모바일 학습 헤더를 제목·코스·자료 수 두 줄로 압축한다.
- [x] 65. 고정 컬렉션을 44px 의미론적 가로 레일로 줄인다.
- [x] 66. 최근 세션을 두 줄 요약과 명시적 다시 동작으로 바꾼다.
- [x] 67. 일반 퀴즈 목록보다 개인화 추천을 먼저 표시한다.
- [x] 68. Practice Hub 추천 캐러셀을 88px로 줄이고 중복 설명을 없앤다.
- [x] 69. 오늘의 도전을 34px 아이콘과 한 줄 보조 문구로 압축한다.
- [x] 70. 최근 게임을 44px 레일로 올리고 마지막 규칙으로 즉시 재실행한다.
- [x] 71. 즐겨찾는 게임을 44px 레일로 올리고 저장 규칙으로 실행한다.
- [x] 72. 게임 검색을 44px 입력으로 줄이고 한 번에 지울 수 있게 한다.
- [x] 73. 적용 중인 시간·기술·정렬 조건 수를 필터 제목에 표시한다.
- [x] 74. 필터·정렬을 펼치지 않고 한 번에 기본값으로 복구한다.
- [x] 75. 검색·필터 결과 수를 live region으로 즉시 알린다.
- [x] 76. 모바일 카테고리 설명을 생략하고 활동 카드를 100px로 줄인다.
- [x] 77. 실행 시트 상단에 현재 규칙 바로 시작을 제공한다.
- [x] 78. 자료 현황을 44px 레일로 합치고 시간 프리셋을 문제 수보다 먼저 표시한다.
- [x] 79. 게임별 고급 규칙을 한 번에 안전한 기본값으로 되돌린다.
- [x] 80. 맞춤 세션의 모바일 요약·프리셋 순서를 압축하고 모든 세부 조건을 한 번에 초기화한다.
