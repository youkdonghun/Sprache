# Sprache 1.38.5

이번 버전은 Android, Windows와 PWA에서 학습 시작과 자료 편집을 더 짧고 직관적으로 만드는 데 집중했습니다.

1. 홈의 주 학습 버튼을 `바로 학습`으로 통일했습니다.
2. 학습 허브의 추천 영역을 `오늘 바로 학습`으로 바꿨습니다.
3. 모바일 학습 설정은 `문제 방식 → 자료 범위 → 문제 수` 세 단계만 먼저 보여줍니다.
4. 모바일의 난이도·기록·태그·일정은 `세부 설정` 한 곳으로 접었습니다.
5. Windows에서도 기본 세 단계만 먼저 보여주고 세부 설정은 필요할 때 펼칩니다.
6. 적용 중인 세부 조건 수를 접힌 상태에서도 확인할 수 있습니다.
7. 세부 조건만 한 번에 초기화하고 기본 문제 방식과 문제 수는 유지합니다.
8. 현재 언어, 실제 문제 수, 예상 시간을 설정 화면 상단에서 바로 확인합니다.
9. 시작 버튼 바로 위에도 현재 언어와 문제 수를 표시합니다.
10. 학습 설정을 바꿀 때마다 최근 초안을 기기에 자동 저장합니다.
11. 제목을 쓰지 않고 저장하면 언어·방식·분량으로 알아보기 쉬운 이름을 만듭니다.
12. 저장한 학습 설정 카드를 누르면 관리 메뉴를 거치지 않고 바로 불러옵니다.
13. 현재 설정과 퀴즈 기록이 어떤 언어·주제에 속하는지 상단에 짧게 안내합니다.
14. 자료실 상단 동작을 `추가`, `표로 수정`, `더보기` 세 가지로 정리했습니다.
15. `표로 수정`은 직접 등록한 자료뿐 아니라 기본 제공 단어와 문장도 함께 편집합니다.
16. 중복되던 일괄 수정 안내 카드와 개별 추가 버튼을 제거했습니다.
17. 휴지통은 평소에는 더보기에 넣고 삭제 자료가 있으면 개수 배지를 표시합니다.
18. 활성 검색 조건을 지우는 동작을 `전체 해제`로 명확히 바꿨습니다.
19. 정상 연결 상태의 Google Drive 설명 카드는 숨기고 연결이 필요할 때만 안내합니다.
20. 320px부터 Windows 넓은 화면까지 새 구성의 오버플로와 편집 흐름을 회귀 검증했습니다.
21. 앱을 완전히 껐다가 다시 열면 공개 릴리스의 새 버전을 한 번 조용히 확인합니다.
22. 새 버전이 있을 때만 상단 안내를 띄우고, 확인 실패나 최신 상태에서는 작업을 방해하지 않습니다.
23. 설정의 업데이트 카드와 시작 안내에서 최신 Android APK 링크를 바로 공유할 수 있습니다.
24. 영어·일본어·독일어·프랑스어·스페인어·중국어 기본 문장을 언어별 100개로 늘렸습니다.
25. 새 문장의 한국어 뜻, 문장 배열 토큰, 일본어 읽기·로마자와 중국어 병음을 함께 넣었습니다.

버전: `1.38.5+73`
