# Sprache 1.36.1 출시 안내

버전은 `1.36.1+62`입니다. 이번 업데이트는 웹 집중 화면과 단어 일괄 편집의 발견성을 높이고, 사이드바 표기를 더 간결하게 다듬었습니다.

- 웹 설정에 브라우저 전체 화면 기반의 `집중 화면`을 추가했습니다.
- PWA 설치 시 주소창 없이 앱처럼 사용하는 방법을 설정 화면에서 바로 확인할 수 있습니다.
- 자료실의 편집 버튼을 `엑셀형 일괄 편집`으로 명확하게 바꾸었습니다.
- Excel·Google Sheets에서 복사한 여러 행을 표 편집기에 한 번에 붙여넣을 수 있습니다.
- 전체 검색 버튼 옆의 단축키 문구를 제거했고, 브랜드 표기를 `Sprache`로 통일했습니다.
