# Sprache 1.38.4

이번 버전은 언어별 퀴즈 관리가 분명하게 보이도록 하고, 설정 화면의 버튼 수를 줄이는 데 집중했습니다.

1. 학습 세션 상단에 현재 언어키 또는 주제키를 표시합니다.
2. 세션 설정과 퀴즈 기록이 현재 언어·주제에만 적용된다는 안내를 추가했습니다.
3. 언어를 바꾸면 해당 언어의 세션 설정과 저장 일정을 다시 불러오는 기존 분리 동작을 회귀 테스트했습니다.
4. 다른 언어에서 진행 중인 퀴즈가 현재 언어의 새 퀴즈를 막지 않는지 검증했습니다.
5. 빠른 설정 네 개를 한 개의 `빠른 설정` 메뉴로 통합했습니다.
6. 문제 방식 버튼들을 한 개의 선택창으로 통합했습니다.
7. 출제 방향 버튼들을 한 개의 선택창으로 통합했습니다.
8. 코스·단원·별표·개인 자료 범위를 한 개의 선택창으로 통합했습니다.
9. 단어·문장 포함 설정을 `단어 + 문장`, `단어만`, `문장만` 선택창으로 바꿨습니다.
10. 문제 수·학습 시간 기준과 시간 프리셋을 각각 한 개의 선택창으로 정리했습니다.
11. 문제 수의 증감 버튼을 없애고 직접 입력과 자주 쓰는 개수 메뉴를 제공했습니다.
12. 난이도, 학습 기록, 출제 순서를 각각 한 개의 선택창으로 정리했습니다.
13. 밀린 복습의 하루 최대량 버튼들을 한 개의 선택창으로 통합했습니다.
14. 저장과 예약 버튼을 한 개의 `저장` 메뉴로 통합하고 시작 버튼을 가장 크게 유지했습니다.
15. 저장된 일정의 불러오기, 순서 변경, 삭제를 한 개의 관리 메뉴로 통합했습니다.
16. 직접 선택 자료의 전체 선택과 해제를 한 개의 관리 메뉴로 통합했습니다.
17. 저장된 일정이 없을 때 빈 안내 카드를 숨겨 핵심 설정이 더 빨리 보이게 했습니다.
18. 세션 초기화는 상단 더보기 메뉴 안으로 옮겨 실수로 누르기 어렵게 했습니다.
19. 작은 Android·PWA 화면에서는 추천 카드 좌우 버튼을 숨기고 스와이프에 집중합니다.
20. Windows에서는 추천 카드 좌우 버튼, 마우스 휠과 키보드 탐색을 계속 지원합니다.

버전: `1.38.4+72`
