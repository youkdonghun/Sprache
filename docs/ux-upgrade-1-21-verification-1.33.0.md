# Sprache 1.33.0 UX 고도화 1~22 검증 기록

작성일: 2026-08-03
대상 버전: `1.33.0+57`
범위: 등록·자료실·저장 위치·학습·게임 UX 1~20, 야구·아이돌 예문 데이터 21,
Practice Hub 가로 탐색 22

## 판정 기준

- `IMPLEMENTED`: 구현과 해당 집중 회귀 검사가 추가된 상태다.
- `DATA REVIEWED`: 배포 데이터의 단어–뜻–예문 연결과 형식 간 값이 대조된
  상태다.
- `PASS`: 실제 명령 출력 또는 산출물·런타임 증거로 완료를 확인한 상태다.
- `NOT RUN (HOST LIMIT)`: 현재 Windows 호스트에서 만들 수 없는 Apple 산출물로,
  Codemagic의 macOS·Xcode 환경에서 별도로 검증해야 하는 상태다.

## 21번 데이터 검토표

| 주제 | 단어 | 뜻과 예문의 일치 기준 |
| --- | --- | --- |
| 야구 | WHIP | 허용 볼넷+안타를 투구 이닝으로 나누는 지표로 통일 |
| 야구 | ERA | 자책점×9÷투구 이닝인 평균자책점으로 통일 |
| 야구 | RBI | 타석 결과로 주자가 득점해 타자에게 부여되는 타점으로 통일 |
| 야구 | OPS | 출루율과 장타율의 합으로 통일 |
| 야구 | 퀄리티 스타트 | 선발 6이닝 이상·3자책점 이하 조건으로 통일 |
| 아이돌 | 최애 | 여러 연예인·멤버 중 가장 좋아하는 사람으로 통일 |
| 아이돌 | 공카 | 가수·소속사가 운영하거나 인증한 공식 팬 카페로 통일 |
| 아이돌 | 응원봉 | 공연장에서 응원할 때 드는 조명 도구로 통일 |
| 아이돌 | 총공 | 같은 목표를 위해 정한 시간대에 함께하는 단체 팬 활동으로 통일 |
| 아이돌 | 출근길 | 연예인이 방송국·행사장에 들어가는 모습 또는 시간대로 통일 |
| 아이돌 | 퇴근길 | 연예인이 방송·행사를 마치고 나오는 모습 또는 시간대로 통일 |
| 아이돌 | 생얼 | 화장하지 않은 자연스러운 얼굴로 통일 |

검토 대상은 번들 JSON, `sample-data/import-template.csv`, 간편·전체 XLSX
템플릿이다. 번들 JSON의 12개 단어 행은 `id`, `example_id`,
`part_of_speech`, 추가 정답, 그룹, 예문 토큰, 출처와 `content_version`을
명시한다. CSV·XLSX에도 반복되는 표본은 번들 값과 맞췄다. 기존 v1 자동 생성
UUID를 그대로 승격했기 때문에 교정본 재가져오기는 새 항목을 중복 생성하지 않고
같은 단어와 예문을 갱신해야 한다.

Apple 항목은 Windows 로컬 환경에서 완료로 판정하지 않는다. iOS Simulator ZIP은
IPA가 아니고 macOS preview ZIP은 공증본이 아니므로, 각각의 용도를 최종 배포본과
구분한다.

## 재현 명령

```powershell
npm run test:release-bundle
npm run analyze:client
npm run test:client
npm run build:real
```

```bash
bash tool/build-apple-preview.sh
```

마지막 명령은 macOS·Xcode가 있는 격리된 Codemagic `apple-preview` 환경에서만
실행한다. 네 플랫폼 결과와 증거 파일이 준비된 뒤
`packaging/release-bundle-spec-1.33.0.json`으로 manifest를 만들고 검증해야
릴리스 완료로 판정한다.
