# 기본 콘텐츠 카탈로그

## 포함 수량

| 코스 | 단어 | 문장 | 읽기 보조 |
|---|---:|---:|---|
| 한국어→영어 | 80 | 20 | 해당 없음 |
| 한국어→일본어 | 80 | 20 | 가나, 로마자 |
| 한국어→독일어 | 80 | 20 | 해당 없음 |
| 한국어→프랑스어 | 80 | 20 | 해당 없음 |
| 한국어→스페인어 | 80 | 20 | 해당 없음 |
| 한국어→중국어(간체) | 80 | 20 | 병음 |

총 단어 480개·문장 120개다. 모든 단어는 품사 분류를 가지며 모든 문장은 명시적 토큰을 포함한다. 객관식, 직접 입력, 문맥 빈칸, 문장 배열, TTS 문제를 지원한다. 각 표현은 의미 기반 단원 태그를 가지며 여섯 언어의 모든 단원에 단어와 문장이 들어 있는지 테스트로 고정한다. 수량, 품사, 출처와 필수 읽기 표기는 자동 테스트로 검증한다.

## 출처와 사용 조건

- 현재 입문 세트는 이 프로젝트를 위해 직접 작성한 짧은 기초 단어·문장이다.
- 외부 코퍼스나 사전의 문장을 복제하지 않았다.
- `sourceVersion=2026.07`, `contentVersion=1`, `license=project-internal`로 항목마다 기록한다.
- `project-internal`은 공개 라이선스가 아니다. 공개 배포 전에 저장소 루트의 최종 `LICENSE`와 콘텐츠 배포 정책을 선택해야 한다.
- 사용자 CSV·JSON·JSONL 가져오기는 개인 데이터로 취급하며 앱이 별도 라이선스를 부여하지 않는다.
- 전체 등록 내용과 외부 콘텐츠 추가 템플릿은 루트 `ATTRIBUTIONS.md`에서 관리한다.

## 검수 체크리스트

- 목표 언어 원어민 검수
- 한국어 번역의 존댓말·문장부호 일관성 확인
- 일본어 가나·로마자와 중국어 성조 부호 확인
- TTS locale별 실제 기기 발음 확인
- 오답 선택지가 정답과 동의어가 되지 않는지 확인
