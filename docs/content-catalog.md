# 기본 콘텐츠 카탈로그

## 포함 수량

| 코스 | 단어 | 문장 | 읽기 보조 |
|---|---:|---:|---|
| 한국어→영어 | 80 | 100 | 한국어 발음 |
| 한국어→일본어 | 80 | 100 | 한국어 발음, 가나, 로마자 |
| 한국어→독일어 | 80 | 100 | 한국어 발음 |
| 한국어→프랑스어 | 80 | 100 | 한국어 발음 |
| 한국어→스페인어 | 80 | 100 | 한국어 발음 |
| 한국어→중국어(간체) | 80 | 100 | 한국어 발음, 병음 |

총 단어 480개·문장 600개, 언어별 180개다. 모든 단어는 품사 분류를 가지며 모든 문장은 명시적 토큰을 포함한다. 객관식, 직접 입력, 문맥 빈칸, 문장 배열, TTS 문제를 지원한다. 각 표현은 의미 기반 단원 태그를 가지며 여섯 언어의 모든 단원에 단어와 문장이 들어 있는지 테스트로 고정한다. 수량, 품사, 출처와 필수 읽기 표기는 자동 테스트로 검증한다.

한국어 발음은 직접 검수한 기초 단어·문장 표기를 우선하고, 표기가 없는 내장
항목은 언어별 오프라인 변환 규칙으로 결정적으로 생성한다. 이 표기는 읽기
진입을 돕는 보조 자료이며 실제 발음의 기준은 앱의 언어별 TTS다.

## 출처와 사용 조건

- 현재 입문 세트는 이 프로젝트를 위해 직접 작성한 짧은 기초 단어·문장이다.
- 외부 코퍼스나 사전의 문장을 복제하지 않았다.
- `sourceVersion=2026.09`, `contentVersion=4`, `license=project-internal`로 항목마다 기록한다.
- `project-internal`은 공개 라이선스가 아니다. 공개 배포 전에 저장소 루트의 최종 `LICENSE`와 콘텐츠 배포 정책을 선택해야 한다.
- 사용자 CSV·JSON·JSONL 가져오기는 개인 데이터로 취급하며 앱이 별도 라이선스를 부여하지 않는다.
- 전체 등록 내용과 외부 콘텐츠 추가 템플릿은 루트 `ATTRIBUTIONS.md`에서 관리한다.

## 선택형 웹 예문 팩

- Tatoeba 원문과 직접 연결된 승인 상태 한국어 번역을 언어별 4개씩, 총
  24개 제공한다.
- 기초 12개와 출퇴근·학습 12개를 따로 열 수 있으며 사용자가 가져오기
  검토 화면에서 선택하기 전에는 자료함에 저장하지 않는다.
- 원문·번역 ID, 두 작성자, 원문 URL, `CC BY 2.0 FR` 표시를 항목별로
  보존한다.
- 두 팩 내부와 팩 사이의 언어·표현 중복, 문장 토큰, 일본어 읽기,
  중국어 병음과 출처 필드는 자동 테스트로 고정한다.
- `npm run check:tatoeba`로 공식 API의 현재 원문·직접 한국어 번역·작성자·
  라이선스·중국어 `Hans` 스크립트를 다시 대조할 수 있다.

## GitHub 다운로드 언어팩

- 공개 팩은 저장소의 `language-packs/packs/`에 보관하고 생성된
  `language-packs/catalog.json`을 앱이 읽는다.
- 현재 TUFS CC BY 4.0 기반 팩 6개를 제공한다. 내장 어휘와 팩 내부 중복을
  제외한 추가 항목은 영어 352, 일본어 402, 독일어 361, 프랑스어 360,
  스페인어 354, 중국어 370개다.
- 출처 정렬 원본과 재현 절차는 `language-packs/sources/`에 보관한다.
- 앱은 카탈로그와 팩이 같은 HTTPS 호스트인지, 파일 크기와 SHA-256이 일치하는지,
  팩 ID·언어·버전·revision·라이선스·항목 수가 같은지 모두 확인한다.
- 검증을 통과해도 자동 저장하지 않고 기존 가져오기 검토 화면에서 신규·변경·중복을
  고른 뒤 반영한다. 같은 자료의 교정판은 안정 ID와 증가한 revision을 사용한다.
- 설치 결과만 사용자 SQLite와 Drive snapshot에 포함한다. 공개 원본 파일은 다시
  Drive에 저장하지 않으며, 새 팩은 앱 배포 없이 카탈로그 새로고침으로 나타난다.

## 검수 체크리스트

- 목표 언어 원어민 검수
- 한국어 번역의 존댓말·문장부호 일관성 확인
- 일본어 가나·로마자와 중국어 성조 부호 확인
- 여섯 언어 한국어 발음 보조표기의 원어민·한국어 화자 교차 검수
- TTS locale별 실제 기기 발음 확인
- 오답 선택지가 정답과 동의어가 되지 않는지 확인
