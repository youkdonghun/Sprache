# Sprache 1.40.1

## 발음 표기 정리

- 예전 영어 언어팩 `2026.09.1`에서 영문 철자를 그대로 옮겨 잘못 생성된
  한글 발음 표기를 자동으로 제거한다.
- 앱을 시작할 때 로컬 자료를 정리하고, Google Drive 병합 및 백업 복원 때도
  같은 검사를 적용해 잘못된 표기가 다시 들어오지 않게 했다.
- 사용자가 직접 등록한 발음, 사용자가 수정한 발음, 현재 팩에서 사람이
  검토한 발음은 보존한다.
- 영어 발음은 부정확한 한글 자동 표기 대신 기기의 실제 TTS 음성으로 들을
  수 있다.

## 검증

- 세 영어팩(TUFS 생활 어휘, TOEIC 어휘, TOSS 어휘)의 구버전 자료를 모두
  정리하는 단위 테스트를 추가했다.
- 시작·Drive 병합·백업 복원 후 잘못된 발음이 남거나 재유입되지 않는 회귀
  테스트를 추가했다.
- Flutter 정적 분석과 전체 테스트, Windows·Android·Web 빌드를 배포 전에
  검증한다.
