# Sprache 1.21.0 검증 보고서

검증일: 2026-07-29

## 변경 범위

- 홈과 전역 내비게이션에서 반복되던 학습·코스·자료 진입점 정리
- 학습 허브를 `퀴즈`·`암기`·`실전` 세 범주로 통합
- 퀴즈 콤보, 3문제 미니 목표, 즉시 피드백, 최고 콤보 결과 추가
- 버전 `1.21.0+37`

## 정보 구조 정리

전역 내비게이션은 Android와 Windows 모두 `오늘`·`학습`·`단어장`·`기록`·
`설정`의 고정된 다섯 항목을 사용한다. 코스, 단원, 노트, 미션, 발음 및 세션
만들기는 별도의 전역 메뉴가 아니라 `학습` 안의 목적별 진입점으로 묶었다.

홈에는 다음 레슨, 오늘 계획, 저장한 일정과 진행 중 세션만 남겼다. 기존 홈에
반복되던 코스 요약, 퀴즈·카드·발음 바로가기, 주간 리듬, 미션 강조, 설정 링크는
제거했다. 학습 허브에서는 긴 활동 섹션 네 개를 없애고 다음 세 범주로 정리했다.

- 퀴즈: 혼합 퀴즈, 뜻 고르기, 직접 쓰기, 문장 빈칸, 문장 배열, 듣고 쓰기
- 암기: 단어 카드, 문장 카드, 단원 노트, 저장한 표현
- 실전: 발음 따라하기, 실전 상황 미션, 취약 복습, 코스 여정

모바일은 2열, Windows는 3열 카드로 표시한다. 일정 만들기는 큰 설명 카드 대신
현재 방식·문제 수·일정 여부를 한 줄에 보여주는 진입점으로 축약했다.

## 퀴즈 개선

정답을 연속으로 맞히면 콤보가 올라가고 오답이면 초기화된다. 상단 추적기는
3문제 미니 목표, 현재 콤보와 남은 문제 수, 실제 세션 XP를 함께 보여준다.
정답 피드백은 연속 정답 수에 따라 달라지며, 오답은 해당 문제가 세션 끝에 다시
나온다는 점과 정답을 바로 안내한다. 결과 화면에는 정확도·정답 수·최고 콤보·
획득 XP를 표시한다.

- Windows Authenticode 코드 서명 인증서
- 소유 도메인의 공개 개인정보처리방침 URL과 Google OAuth 게시 검토
