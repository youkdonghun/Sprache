# Sprache 1.38.5 기본 콘텐츠 확장 검토

## 이번 배포에 포함한 범위

- 영어·일본어·독일어·프랑스어·스페인어·중국어 문장을 언어별 40개에서
  100개로 확장했다.
- 새 문장 360개는 일상, 가정, 업무, 학습, 연락, 건강 상황을 중심으로
  프로젝트에서 직접 작성했다.
- 모든 문장에 한국어 뜻과 수동 문장 배열 토큰을 넣었다.
- 일본어에는 가나와 로마자, 중국어에는 병음을 함께 넣었다.
- 내장 카탈로그는 단어 480개와 문장 600개, 총 1,080개다.

## 어휘 1,000개·시험 어휘 5,000개를 바로 넣지 않은 이유

앱의 기본 자료는 표현, 한국어 뜻, 언어, 품사, 발음, 출처가 함께 맞아야 한다.
단순 빈도 목록이나 자동 번역 결과를 1,000개로 잘라 넣으면 동형어의 뜻,
품사, 일본어 읽기와 중국어 병음이 틀릴 수 있고 자료실도 불필요하게 무거워진다.

2026-09-02에 공개 원본을 실제 데이터 단위로 확인한 결과는 다음과 같다.

| 후보 | 확인 결과 | 이번 포함 여부 |
| --- | --- | --- |
| TUFS Basic Vocabulary Wordnets | CC BY 4.0이며 교육용 핵심 어휘와 예문을 제공한다. 한국어와 같은 개념 ID로 직접 맞는 고유 개념은 영어 501, 일본어 443, 독일어 477, 프랑스어 497, 스페인어 494, 중국어 488개였다. | 목표 1,000개에 미달해 보류 |
| Open English-Korean Dictionary | 48,000개 이상과 한국어 뜻을 제공하지만 저장소 자체 설명상 여러 공개 원본과 LLM 보강 자료의 결합이며 TOEIC·TOEIC Speaking 공식 분류가 없다. | 시험명으로 허위 분류하지 않기 위해 보류 |
| CodingFriends Basic Vocabulary | 한국어와 여러 언어 조합이 있으나 언어별 200여 개이며 CC BY-NC 4.0이다. | 목표 수량·배포 정책에 맞지 않아 보류 |

## 다음 포함 조건

어휘 팩은 다음 조건을 모두 만족할 때 기본 설치 자료와 분리된 선택형 팩으로
추가한다.

1. 언어별 1,000개의 한국어 뜻과 품사가 검수되어야 한다.
2. 일본어 가나·로마자와 중국어 병음이 원본 또는 검수 데이터로 있어야 한다.
3. TOEIC·TOEIC Speaking 이름을 쓸 경우 공식 또는 재배포 가능한 시험 분류
   근거가 있어야 한다.
4. 원본 ID, 버전, URL, 저자, 라이선스와 가공 기록을 항목별로 보존해야 한다.
5. 기본 자료실을 무겁게 만들지 않도록 사용자가 원하는 팩만 받게 해야 한다.

사용자가 소유한 교재·어휘표는 현재 Excel·CSV·PDF 가져오기와 일괄 편집을
통해 바로 사용할 수 있으며, 이 경우 기본 라이선스는 `private`로 유지한다.
