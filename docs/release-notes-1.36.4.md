# Sprache 1.36.4

## 기본 학습 자료 편집

- 앱에 처음부터 들어 있는 단어와 문장도 자료실에서 바로 수정할 수 있습니다.
- 기본 자료를 고치면 원본은 보호되고, 같은 항목의 `내 편집본`이 저장되어 자료실·퀴즈·복습에 우선 적용됩니다.
- 개별 편집 화면에서 기본 자료를 수정 중인지 명확히 안내합니다.

## Excel형 일괄 수정

- Excel형 일괄 수정 화면에 기본 자료와 사용자 자료를 모두 표시합니다.
- 각 행에 `기본` 또는 `내 편집본` 상태를 표시합니다.
- 셀 직접 수정과 Excel·Google Sheets 표 붙여넣기로 기본 자료도 한 번에 바꿀 수 있습니다.
- 실제로 바꾼 기본 행만 `내 편집본`으로 저장하고 Google Drive 동기화 대상에 포함합니다.
