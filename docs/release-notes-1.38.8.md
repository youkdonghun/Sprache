# Sprache 1.38.8

## 단순해진 기본 학습

- 학습 허브의 기본 선택지를 `뜻풀이`, `뜻 보고 단어 선택`, `문장 맞추기`로
  줄였다. 세 카드는 별도 설정 창 없이 저장된 기본값으로 바로 시작한다.
- 기존 추천, 전체 게임, 미션, 카드, 듣기, 발음, 시험, 플레이리스트와
  맞춤 세션은 삭제하지 않고 `더 많은 학습 방식` 안에 접어 두었다.
- `뜻 보고 단어 선택`은 뜻을 질문으로, 학습 언어 표현을 선택지로 사용하는
  실제 역방향 선택형 퀴즈다. 일반 뜻풀이와 진도·오답 기록 규칙을 공유한다.

## 설정과 화면 정리

- 설정을 열면 검색과 저장·화면·학습·집중 화면·데이터·앱 정보 목록만 보인다.
  긴 설명과 세부 조작은 선택한 항목 안에서만 표시한다.
- 중복된 설정 바로 이동 버튼과 전체 초기화 버튼을 첫 화면에서 제거했다.
  화면 설정과 학습량의 개별 초기화는 해당 상세 항목에 그대로 유지된다.
- 학습 허브의 소개 문구와 최근 학습 카드의 중복 실행 버튼을 줄였다.

## Android·iPhone 앱 공유

- 설정의 앱 정보에서 `앱 설치 링크 공유`를 누르면 Android APK와 iPhone PWA
  링크를 함께 시스템 공유창으로 보낸다.
- iPhone Safari와 Android에서는 각 운영체제 공유창을 사용하고, 공유창을
  사용할 수 없는 환경에서는 두 설치 링크를 클립보드에 복사한다.

## 검증 범위

- 세 가지 기본 학습만 노출되는 초기 상태와 고급 학습 펼치기 동작
- 뜻→단어 역방향 선택지, 정답 판정, 경로 복원
- 설정 개요·검색·상세 카테고리·개별 초기화
- Flutter 전체 테스트와 정적 분석
- Android APK, Windows 배포판, GitHub Pages PWA 빌드
