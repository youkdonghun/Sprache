# Sprache 1.32.0 릴리스 노트

버전: `1.32.0+56`

## 한눈에 보기

1.32.0은 새 기능을 늘리기보다 자주 쓰는 학습 흐름의 선택 수, 카드 높이,
반복 설명과 이동 거리를 줄이는 릴리스다. 구현 범위는
[컴팩트 UX 80개 목표](compact-ux-80-upgrade-plan-1.32.0.md)에 고정한다.

## 앱 잠금처럼 보이던 화면 제거

- 백그라운드 복귀 뒤 표시되던 `Sprache 보호 중` 커튼과 지연 타이머·설정을
  제거했다.
- 1.31 설정 백업에 남아 있는 `curtainDelay`는 오류 없이 무시하므로 기존 로컬
  데이터와 백업을 그대로 열 수 있다.
- 개인정보 가림, 알림 내용 표시, Drive 동기화 일시 중지를 서로 다른 기능으로
  설명한다. 이 변경은 로컬 데이터 암호화나 OS 보안 저장소를 약화하지 않는다.

## 더 컴팩트한 기본 화면

- 화면 밀도 토큰을 사이드바, 상단 주제 바, 페이지·카드·섹션 간격에 함께
  적용했다. Windows 기본 사이드바도 좁아졌지만 주요 조작 영역은 최소 44px을
  유지한다.
- 홈은 이어하기를 최우선으로 두고 오늘 할 일은 한 줄 지표, 주간 목표는 진행
  스트립으로 압축했다. 복습 0건도 큰 빈 카드로 표시하지 않는다.
- 좁은 화면에서는 보조 통계와 설명이 자연스럽게 줄바꿈되거나 축약된다.

## 단어 등록과 자료실

- 빠른 등록을 열면 표현·뜻이 먼저 보이며, 읽기·예문·태그와 그룹 검색·생성,
  템플릿·바구니 도구는 필요할 때 펼친다.
- 마지막 언어, 자료 종류와 그룹 기본값을 재사용하며 중복 상태와 저장 동작을
  입력 흐름 가까이에 둔다.
- 자료실의 검색·그룹 필터를 결과 가까이에 모으고, 데이터 흐름 안내는 짧은
  요약으로 시작해 상세 설명을 선택적으로 펼친다.

## 연습·게임과 개인화

- 개인 추천과 연습 진입점을 더 낮은 행으로 압축하고 실수·단어·듣기·말하기·
  게임을 한 허브에서 훑을 수 있게 했다.
- 3·5·10·15분 프리셋과 예상 문제 수를 즉시 보여 주며, 최근 사용·즐겨찾기
  모드를 먼저 배치한다.
- 문제 수·난이도·형식은 바로 보이고 순서·기록·세부 제한은 `고급 설정`에
  접힌다.
- 새 `컴팩트 작업 공간` 프리셋은 밀도, 탐색 레이블과 홈 모듈을 한 번에
  정리하며 다른 프리셋으로 언제든 되돌릴 수 있다.

## 2차 컴팩트화 50개

- 좁은 Windows 창은 하단 탐색으로 자동 전환하고, 사이드바의 검색·추가·도움말과
  주제·저장 상태를 각각 한 줄로 합쳤다.
- 빠른 등록은 넓은 화면의 표현·뜻과 하단 동작을 한 행으로 모으고, 중복 비교와
  새 그룹 입력은 요청할 때만 펼친다. 자료실에는 원탭 단어 추가와 결과·필터별
  수량을 추가했다.
- 연습 허브는 추천→최근→즐겨찾기 순서로 재배치하고 추천 행을 88px로 낮췄다.
  검색 결과 수, 필터·규칙 초기화, 상단 바로 시작과 세션 세부 조건 전체 초기화를
  제공한다.

## 호환성과 저장 범위

- 데이터베이스 스키마와 학습 콘텐츠 형식은 변경하지 않는다.
- 언어별 코스·복습 큐 분리, 계정 단위 XP·레벨·연속 학습일·배지 합산,
  Local-First 저장과 tombstone 동기화 원칙은 그대로다.
- 사용자 학습 콘텐츠와 상세 진도는 Railway PostgreSQL에 저장하지 않는다.

## 전달 산출물 표시

| 플랫폼 | 표준 파일 | 표시 | 검증 범위 |
|---|---|---|---|
| Windows | `Sprache-Windows-Setup-1.32.0-google-x64.exe` | `REAL` | 실제 설치·첫 프레임 `RUNTIME` |
| Android | `Sprache-Android-1.32.0-google-debug-signed.apk` | `REAL` | 패키지·버전·ABI·v2 서명 `BUILD_ONLY` |
| iOS | `Sprache-iOS-Simulator-1.32.0-mock.zip` | `MOCK` | GitHub macOS runner의 Simulator `RUNTIME` |
| macOS | `Sprache-macOS-1.32.0-mock.zip` | `MOCK` | GitHub macOS runner의 unsigned/ad-hoc `RUNTIME` |

Windows 설치본은 코드 서명 인증서가 없으면 기능 검증용 무서명 파일이다.
Android의 `debug-signed` APK는 Play 배포본이 아니며, iOS ZIP은 IPA가 아니고
macOS ZIP은 공증된 배포 앱이 아니다. 실제 빌드·실행 결과와 SHA-256은 최종
`release-manifest-1.32.0.json` 및 결속된 evidence가 우선한다.
