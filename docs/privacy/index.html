Sprache 개인정보처리방침

시행일: 2026년 8월 3일

Sprache는 Android와 Windows에서 동작하는 Local-First 학습 앱입니다. Google 연결은 선택 사항이며, 연결하지 않아도 로컬 학습을 사용할 수 있습니다.

Sprache는 광고나 데이터 판매를 하지 않습니다. 별도 Sprache 서버는 학습 자료, 상세 진도, Google 계정 연결 정보 또는 OAuth 토큰을 수집·보관하지 않습니다.

1. 처리하는 정보

  • 기기 로컬 데이터: 사용자가 만든 단어·문장·예문, 뜻, 읽기, 그룹, 일정, 가져오기 이력, 진도, XP, 오답, 최근 세션과 앱 설정
  • Google 계정 정보: 사용자가 연결을 선택할 때 Google이 앱에 제공하는 계정 식별자, 이메일과 기본 프로필 정보. 이 정보는 연결 계정을 표시하고 구분하는 데 사용되며 별도 Sprache 서버로 전송하지 않습니다.
  • Google Drive 학습 데이터: 사용자가 선택한 위치의 WordStudyData에 저장되는 동기화 snapshot, manifest, 파일 ID, revision과 checksum
  • Google Drive 숨김 연결 설정: appDataFolder에 저장되는 WordStudyData 폴더 ID·이름 포인터. 단어·문장·진도와 토큰은 이 파일에 넣지 않습니다.
  • 로컬 연결 정보: Drive 파일 ID, 마지막 동기화 시각과 충돌 상태. OAuth 토큰은 운영체제 보안 저장소에 보관합니다.
  • 공개 문서 접속 정보: 이 정적 사이트의 호스팅 제공자인 GitHub가 보안과 운영을 위해 일반 웹 접속 로그를 처리할 수 있습니다. Sprache 페이지 자체는 분석 도구, 광고 추적기, 입력 폼 또는 쿠키를 사용하지 않습니다.

2. Google 사용자 데이터 사용 목적과 범위

Sprache는 사용자가 Google 연결을 선택했을 때 다음 범위를 요청합니다.

  • openid, email, profile: 연결할 Google 계정 확인과 앱 안의 계정 표시
  • https://www.googleapis.com/auth/drive.file: 사용자가 선택했거나 Sprache가 만든 Drive 학습 파일을 생성·조회·갱신·삭제
  • https://www.googleapis.com/auth/drive.appdata: 숨겨진 appDataFolder에서 Drive 학습 폴더 연결 포인터를 생성·조회·갱신·삭제

drive.file은 사용자가 선택했거나 Sprache가 만든 파일로 접근을 제한합니다. appDataFolder는 일반 Drive 파일 목록에 표시되지 않으며, Sprache는 여기에 폴더 연결 포인터만 둡니다. Google 데이터는 기기 간 학습 연속성, 백업과 복원에만 사용합니다.

Sprache의 Google API 데이터 사용은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다.

3. 저장 위치와 보존

  • 학습 데이터의 작업 원본은 기기의 SQLite 데이터베이스입니다.
  • Google 연결을 켜면 검증된 동기화 자료를 사용자가 고른 Drive 위치의 WordStudyData에 저장하고, 숨김 앱 설정에는 폴더 연결 포인터만 저장합니다.
  • Windows는 시스템 브라우저, loopback callback과 PKCE 및 Google이 발급한 설치형 앱 자격정보를 사용해 Google 토큰 엔드포인트에 직접 인증 코드를 교환합니다. 별도 Sprache 인증 서버를 거치지 않습니다.
  • Windows OAuth 토큰은 운영체제 보안 저장소에 보관합니다. Android·iOS·macOS 인증 정보는 Google Sign-In 계층과 플랫폼 보안 저장소를 사용합니다.
  • 연결 해제만으로 로컬 자료, Drive 학습 폴더나 숨김 연결 포인터를 자동 삭제하지 않습니다. 삭제 기능마다 대상과 영향을 따로 확인합니다.

4. 공유·이전·판매

Sprache는 Google 사용자 데이터와 학습 데이터를 광고, 판매, 신용 판단, 사용자 프로파일링 또는 AI 모델 학습에 사용하지 않습니다. 다음 제공자는 사용자가 요청한 기능의 범위에서만 데이터를 처리합니다.

  • Google Identity·Drive: 계정 연결, 사용자가 선택한 앱 폴더 동기화와 폴더 포인터 보관
  • 운영체제 음성 서비스: 사용자가 시작한 발음 연습의 마이크 입력 처리. 처리 방식은 운영체제와 사용자의 음성 서비스 설정을 따릅니다.
  • GitHub Pages: 이 개인정보처리방침, 앱 소개와 약관의 정적 호스팅

법률상 의무가 있는 경우를 제외하고 위 목적 밖의 제3자에게 데이터를 공개하지 않습니다.

5. 발음 연습과 마이크

마이크는 사용자가 발음 연습을 시작할 때만 사용합니다. Sprache는 원본 오디오 파일이나 전체 인식 문장을 Drive에 동기화하지 않으며, 학습에 필요한 성공·재연습 결과만 일반 진도로 기록합니다.

6. 보호 조치

  • Google과의 통신에 HTTPS 사용
  • Windows OAuth의 PKCE, 무작위 state와 로컬 loopback callback 검증
  • OAuth 토큰의 운영체제 보안 저장소 사용과 인증 코드·PKCE verifier의 로그 제거
  • Drive revision·SHA-256·schema 검증 뒤에만 원격 자료 병합
  • 손상되거나 지원하지 않는 원격 자료가 정상 로컬 자료를 덮어쓰지 못하도록 격리

7. 사용자의 선택과 삭제

  • Google 연결 없이 로컬 모드로 계속 학습할 수 있습니다.
  • 이 기기에서 연결 해제하면 이 기기의 Google 인증 정보만 제거하고 로컬 자료는 유지합니다.
  • Drive 연결 기록 삭제는 숨김 폴더 포인터를 지우며, WordStudyData의 학습 파일은 지우지 않습니다. Drive 학습 자료 삭제는 별도 기능에서 대상을 다시 확인합니다.
  • Google 계정의 연결된 앱 관리에서 Sprache 접근 권한을 철회하고 숨겨진 앱 설정을 삭제할 수 있습니다.
  • 사용자가 만든 학습 항목과 로컬 백업은 앱 또는 운영체제에서 직접 삭제할 수 있습니다.

8. 정책 변경과 문의

데이터 처리 방식이 달라지면 이 문서의 시행일과 내용을 갱신하고, 중요한 변경은 앱 또는 공개 프로젝트 페이지에서 알립니다.

개인정보 및 데이터 처리 문의: Sprache 프로젝트 문의 페이지

English summary

Sprache is a local-first study app. Google connection is optional. When enabled, drive.file limits access to files the user selected or Sprache created in WordStudyData. The hidden appDataFolder stores only a pointer to that folder, not study content or progress.

Study content and detailed progress remain local unless Drive synchronization is enabled. Sprache does not operate a backend that stores account bindings, study data, authorization codes, or OAuth tokens. Windows exchanges authorization codes directly with Google using PKCE, and tokens are kept in OS-protected storage.

Sprache does not sell data, serve ads, profile users, or use Google user data to train AI models. Users can disconnect Google, revoke access in their Google Account, remove the hidden folder pointer, and separately delete Drive or local study data.
