# Sprache 1.38.9

## 더 빠른 추가와 검색

- 내 자료와 기본 자료를 합친 결과를 한 번만 만들고, 언어별 목록과 동일 자료 찾기
  인덱스를 캐시한다. 자료가 바뀌면 관련 캐시만 다시 만든다.
- 전체 검색은 180ms 입력 대기 후 시작하고 항목을 작은 묶음으로 나누어 처리한다.
  검색어가 바뀌면 오래된 작업을 중단하므로 입력 중 화면이 굳지 않는다.
- 빠른 추가는 커서 선택 변경을 내용 변경과 구분한다. 중복, 비슷한 자료, 예문,
  태그와 그룹 추천은 220ms 대기 후 계산하고 필요한 설정 값만 구독한다.

## GitHub 언어팩 받기

- `자료실 → 추가 → GitHub 언어팩 받기`를 독립된 큰 메뉴로 노출했다.
- 전체 메뉴 검색에서도 `언어팩`, `language pack`, `vocabulary pack`으로 찾을 수 있다.
- 공개 카탈로그에는 영어 352개, 일본어 402개, 독일어 361개, 프랑스어 360개,
  스페인어 354개, 중국어 간체 370개의 추가 어휘가 들어 있다.
- 다운로드한 팩은 크기와 SHA-256, 형식, 언어, 버전, 라이선스를 검증한 다음 기존
  가져오기 검토 화면으로 넘긴다. 사용자가 확인하기 전에는 자료를 저장하지 않는다.
- 설치한 자료는 다른 사용자 자료와 동일하게 로컬 SQLite에 저장되고, Google Drive가
  연결되어 있으면 기존 동기화 흐름을 따른다.

## 검증

- 동기식 검색과 분할 검색 결과 일치, 오래된 검색 취소, 메뉴 검색 경로를 테스트했다.
- 추가 메뉴에서 언어팩 진입점이 명확하게 보이는지 위젯 테스트로 확인했다.
- 실제 GitHub 카탈로그의 6개 팩을 파싱하고 항목 수, 출처, 언어와 뜻을 검증했다.
