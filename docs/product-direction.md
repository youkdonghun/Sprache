# Sprache 제품 방향

최종 수정: 2026-07-27

## 한 문장 정의

Sprache는 한국어 사용자가 Android와 Windows를 오가며 여섯 언어의 표현을 **먼저 이해하고, 문장에 넣고, 듣고, 직접 말한 뒤 간격 반복으로 오래 기억하게 하는** 로컬 우선 학습 앱이다.

## 제품 원칙

1. **퀴즈보다 학습 흐름이 먼저다.** 처음 보는 표현에 바로 정답을 요구하지 않는다. 카드와 단원 가이드로 뜻·읽는 법·발음을 먼저 보여 준다.
2. **인식에서 생성으로 올라간다.** 카드 → 뜻 고르기 → 직접 쓰기 → 문장 만들기 → 듣기 → 말하기 순으로 난도를 높인다.
3. **문법 항목보다 의사소통 목표로 묶는다.** “인사하고 소개하기”, “음식 주문하기”처럼 실제로 할 수 있는 행동을 단원 목표로 삼는다.
4. **추천하되 가두지 않는다.** 홈은 다음 레슨 하나를 분명하게 추천하지만, 코스 여정과 자유 학습에서 모든 단원·활동을 직접 선택할 수 있다.
5. **복습은 별도 벌점이 아니라 코스의 일부다.** 학습 기록, 정확도, 숙련 단계로 다음 활동과 복습 시점을 정한다.
6. **여섯 언어에 같은 골격, 언어별 다른 보조를 쓴다.** 영어·일본어·독일어·프랑스어·스페인어·중국어 간체가 같은 코스 구조를 공유하고, 일본어 읽기와 중국어 병음 같은 보조 정보는 언어별로 제공한다.
7. **Android는 집중형, Windows는 은은한 업무형이다.** 모바일은 큰 터치 영역과 즉각적인 피드백을, Windows는 크기 조절과 낮은 시각적 소음을 우선한다.
8. **Local-First를 기본값으로 둔다.** 로그인하지 않아도 모든 핵심 학습이 가능하고, Google Drive 연결은 기기 간 동기화 선택지다.

## 현재 학습 구조

### 6개 입문 단원

| 순서 | 단원 | 의사소통 목표 |
| --- | --- | --- |
| 1 | 인사와 첫 만남 | 인사하고 내 이름을 소개한다 |
| 2 | 사람과 일상 | 가족과 주변 사람에 대해 말한다 |
| 3 | 시간과 하루 | 시간과 일상적인 행동을 표현한다 |
| 4 | 음식과 주문 | 원하는 음식과 물건을 부탁한다 |
| 5 | 이동과 여행 | 장소를 묻고 이동에 필요한 말을 한다 |
| 6 | 실전 대화 | 도움을 요청하고 짧은 대화를 이어 간다 |

각 단원은 핵심 단어·핵심 문장·학습 순서·진행률을 보여 준다. 사용자는 모바일의 `오늘·코스·연습·단어장·기록` 탭이나 Windows 사이드바에서 원하는 공간으로 바로 이동한다.

### 활동 사다리

| 단계 | 활동 | 학습 의도 |
| --- | --- | --- |
| 1 | 카드로 익히기 | 정답 압박 없이 표현·뜻·발음을 처음 만난다 |
| 2 | 뜻 확인하기 | 쉬운 인식 문제로 기억 흔적을 확인한다 |
| 3 | 직접 써 보기 | 한국어 뜻을 보고 목표 언어를 생성한다 |
| 4 | 문장 만들기 | 빈칸과 배열로 문장 구조를 익힌다 |
| 5 | 듣고 이해하기 | TTS를 듣고 받아쓰며 소리와 철자를 연결한다 |
| 6 | 소리 내어 말하기 | 목표 발음을 듣고 마이크로 따라 말한다 |

### 실전 상황 미션

각 단원은 첫 만남, 친구와 일상, 하루 계획, 카페와 식당, 역과 거리, 도움 요청 상황으로 연결된다. 미션은 표현을 `듣기 → 뜻 확인 → 소리 내어 말하기` 순서로 사용하게 하고, 완료 후 발음 채점이나 문장 문제로 이어진다. 점수를 매기지 않는 연습 단계와 평가 단계를 분리해 처음 말할 때의 부담을 낮춘다. 완료 기록은 언어·단원별로 Local-First 저장되어 미션 목록의 실제 진행 배지에 반영된다.

### 표현 노트와 저장한 표현

각 언어의 6개 단원에는 핵심 문형, 한국어 의미, 예문 2개, 사용 맥락, 발음 포인트가 있다. 사용자는 단원 가이드나 학습실에서 노트를 읽고 같은 단원의 카드·문장·실전 미션으로 바로 이동한다. 다시 보고 싶은 단어와 문장은 별표로 저장하고, 진도나 복습 예정일과 관계없이 `저장한 표현` 모드에서 꺼내 연습한다.

## 다음 고도화 순서

1. 현재 핵심 문형 노트를 문화 설명, 오답 근거, 분기형 대화까지 확장한다.
2. 카드 자기평가와 문제 정답 기록을 하나의 숙련도 모델로 합친다.
3. 학습 전 진단으로 이미 아는 표현을 건너뛰고 추천 단원을 조정한다.
4. 최소 대립쌍, 억양, 문장 단위 쉐도잉을 포함한 발음 피드백을 강화한다.
5. 주간 리듬을 주간 계획, 쉬는 날, 복습 부채를 고려한 개인화 일정으로 발전시킨다.
6. Google Drive 실기기 동기화, 숨김 연결 포인터와 구버전 폴더 재발견을
   반복 검증한다.

## 기능 판단 체크리스트

새 기능은 아래 질문에 모두 답할 수 있을 때 추가한다.

- 사용자가 무엇을 새로 이해하거나 말할 수 있게 되는가?
- 처음 배우기와 복습 중 어디에 속하는가?
- 읽기·쓰기·듣기·말하기 중 어떤 능력을 훈련하는가?
- 코스 여정과 자유 학습 중 어디에서 발견되는가?
- 작은 Windows 창과 375px Android 화면에서 조작 가능한가?
- 로그인과 네트워크가 없어도 핵심 흐름이 유지되는가?
