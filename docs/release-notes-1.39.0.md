# Sprache 1.39.0

## 바로 찾는 학습 자료

- 홈의 두 개 빠른 행동을 `빠른 추가`와 `무료 자료`로 정리했다.
- 자료실의 `추가`를 열면 `무료 추천 학습 자료`가 첫 번째로 보인다.
- 학습할 자료가 없는 경우에도 직접 입력보다 추천 자료 받기를 먼저 안내한다.
- 전체 메뉴 검색에서도 `언어팩`, `단어팩`, `무료 자료`로 같은 화면을 열 수 있다.

## 두 단계로 줄인 언어팩

- 첫 화면에는 현재 학습 언어의 자료만 보여 준다.
- 다른 언어 선택과 출처·버전·파일 크기는 펼침 영역 안으로 옮겼다.
- 자료를 받으면 `추가할 개수`와 `추가하기` 버튼을 먼저 보여 준다.
- 이미 있는 자료는 자동으로 건너뛰고, 문제가 있는 항목은 저장하지 않는다.
- 개별 항목·필터·일괄 선택은 `추가될 자료 살펴보기`를 펼쳤을 때만 보인다.

## 자료실과 설정 정리

- 모바일의 자료 선택과 그룹 정리를 하나의 메뉴로 합쳤다.
- 표로 일괄 수정은 노출을 유지하고, 중복 정리·그룹 정리·휴지통은 자료 관리 메뉴에 모았다.
- Drive가 연결되지 않았다는 이유만으로 자료실에 저장 구조 안내를 상시 표시하지 않는다.
- 0개인 취약·오답 자동 모음과 모바일 검색 예시를 숨겼다.
- `운영자 서버`, `GitHub`, `SHA-256`, `오류 보고서`처럼 학습에 필요하지 않은 기술 표현을 사용자 화면에서 제거했다.
- 업데이트 안내에서 Android·Windows는 구분하기 쉬운 파일명을 사용하고, iPhone·Mac은 설치 파일 대신 PWA로 연결한다.

## 검증

- 320~430px, 1.3배 텍스트, 라이트·다크 테마에서 홈·자료실·추가 메뉴를 확인했다.
- 현재 언어 필터, 빈 목록, 언어팩 전용 확인 흐름을 위젯 테스트로 고정했다.
- 기존 가져오기·일괄 수정·그룹·검색·개인정보 흐름의 회귀를 확인했다.
