# Sprache 1.36.3

- 자료실 상단에 `내가 등록한 단어·문장` 관리 영역을 추가했다.
- 등록 자료 목록에 연필 버튼을 바로 노출해 표현, 뜻, 발음, 예문, 태그를 하나씩 수정할 수 있게 했다.
- `내가 등록` 필터로 직접 추가하거나 가져온 자료만 모아볼 수 있게 했다.
- Excel·Google Sheets용 표를 복사하고, 수정한 표를 다시 붙여 여러 행을 한 번에 저장할 수 있게 했다.
- 표의 행 순서가 바뀌어도 `자료 ID`로 기존 단어·문장을 매칭해 잘못된 항목이 수정되지 않도록 했다.
- 기본 언어팩 자료는 원본을 보호하고, 사용자가 등록한 자료만 일괄 수정하도록 기존 안전 규칙을 유지했다.
