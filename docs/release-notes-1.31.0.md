# Sprache 1.31.0 릴리스 노트

버전: `1.31.0+55`

작성일: 2026-08-03

1.31.0은 Sprache를 “정해진 화면을 쓰는 단어 앱”에서 “내 학습 방식과 기기에
맞게 조정하는 Local-First 학습 도구”로 확장한다. 개인화·빠른 등록·검색·게임
자율성·접근성·데이터 안전·오프라인·플랫폼 연속성·릴리스 품질의 200개 목표를
구현 체크리스트와 범위별 감사로 고정했다.

대표 변화는 실시간 테마 스튜디오와 프로필, 등록 템플릿·바구니·중복 병합,
고급 로컬 검색과 데스크톱 2단 자료실, 자유로운 게임 필터·플레이리스트,
적응형 학습과 주간 목표, 스크린리더·키보드·TTS 개인화, 복구 체크포인트와
완전 오프라인 잠금, 안전한 대용량 가져오기, 학습 루틴과 개인정보 보호다.

아래 목록은 [200개 목표 원본](personalization-200-upgrade-plan-1.31.0.md)과 같은
번호를 사용한다.

## 1–10 · 테마 프리셋과 색상

1. 홈·퀴즈·카드가 함께 보이는 실시간 테마 미리보기를 제공한다.
2. 기존 화면으로 돌아가는 `Sprache 기본` 프리셋을 제공한다.
3. 정보와 애니메이션을 줄인 `집중` 프리셋을 제공한다.
4. 따뜻한 표면과 좁은 읽기 폭의 `종이` 프리셋을 제공한다.
5. 완전 검정 표면과 최소 동작의 `OLED 밤` 프리셋을 제공한다.
6. 주황·남색 Sunrise 강조색을 추가한다.
7. 장시간 학습용 Mint 강조색을 추가한다.
8. 부드러운 Rose 강조색을 추가한다.
9. 색 자극을 줄인 Mono 강조색을 추가한다.
10. 중립·따뜻한 종이·차가운 회색 표면 색감을 선택한다.

## 11–20 · 화면 밀도와 홈 구조

13. 일반·선명한 글자 굵기를 선택한다.
14. 강제 고대비와 키보드 포커스 강조를 독립 선택한다.
15. 초대형 글자와 행간·문단 폭 프로필을 제공한다.
16. 데스크톱 본문 폭을 집중·균형·넓게 중 선택한다.
17. 화면 전환 효과를 전체·은은하게·끄기로 조절한다.
18. 정답·완료 축하 효과를 풍부·간결·끄기로 조절한다.
19. 홈을 집중·균형·인사이트 레이아웃으로 전환한다.
20. 홈 인사말과 주제 헤더를 표시하거나 숨긴다.

## 21–30 · 홈 정보와 섹션 개인화

24. 오늘 계획 카드를 표시하거나 숨긴다.
25. 고정 컬렉션 선반을 표시하거나 숨긴다.

## 31–40 · 내비게이션과 빠른 등록 기본값

31. 하단 내비게이션 라벨을 항상·선택 시·아이콘 중심으로 바꾼다.
32. 전역 빠른 추가 버튼 표시 여부를 선택한다.

34. 학습 주제 전환기를 전체·간단 보기로 바꾼다.
35. 빠른 등록 기본 종류를 단어·문장·마지막 사용으로 선택한다.
36. 예문·읽는 법 등 상세 필드를 처음부터 펼칠지 선택한다.
37. 새 자료를 기본 즐겨찾기로 지정할지 선택한다.

39. 중복 발견 시 질문·병합·별도 저장의 기본 동작을 지정한다.
40. 저장 직전 NFKC·공백 정규화를 자동 적용할지 선택한다.

## 41–50 · 연속 등록과 게임 발견

41. 저장 흐름을 저장 후 닫기·계속 추가 중 선택한다.
42. 연속 등록에서 마지막 태그를 기억하고 추천한다.
43. 초안 자동 저장 간격을 빠르게·균형·느리게 조절한다.
44. 필수 입력 완료 상태를 실시간 표시한다.
45. 추천 단원이 바뀌어도 즐겨찾기가 유지되는 안정적인 게임 ID를 사용한다.
46. 최근 플레이 게임을 별도 선반에서 바로 다시 연다.
47. 즐겨찾는 게임 순서를 앞·뒤로 조정한다.
48. 저장한 게임 규칙으로 설정 창 없이 바로 시작한다.
49. 날짜와 학습 주제에 따라 고정되는 오늘의 도전을 제공한다.
50. 최근 정확도·오답·복습량을 근거로 추천 이유를 표시한다.

## 51–60 · 등록 템플릿과 작업대

51. 종류·그룹·태그·품사·우선순위를 묶은 등록 템플릿을 로컬 저장한다.
52. 템플릿 생성·이름 변경·복제·삭제·고정·순서 변경을 제공한다.
53. 템플릿을 한 번 눌러 적용하되 작성한 표현·뜻은 보존한다.
54. 여러 표현을 담아 한꺼번에 저장하는 로컬 등록 바구니를 제공한다.
55. 바구니 항목별 필수 입력·읽기·토큰·중복 상태를 배지로 표시한다.
56. 바구니 전체에 그룹·태그·즐겨찾기·우선순위를 일괄 적용한다.
57. 중복 발견 시 기존 값과 신규 값의 뜻·읽기·예문·태그를 비교한다.
58. 병합 전 추가·유지·충돌 필드를 요약한다.
59. Enter·Shift+Enter로 필드를 이동하고 마지막 필드에서 저장한다.
60. 최근 5회의 등록·병합 작업을 세션 안에서 되돌린다.

## 61–70 · 검색과 자료실 탐색

61. 최근 검색어를 주제별·전체 검색별 최대 20개 보관하고 삭제한다.
62. 빈 검색창에 최근 검색과 자주 사용한 태그를 제안한다.
63. `tag:`·`type:`·`state:`·`group:` 로컬 검색 연산자를 지원한다.
64. 표현·뜻·읽기·태그의 실제 일치 부분을 강조한다.
65. 결과가 없으면 로컬 카탈로그 기반 유사 검색어를 제안한다.
66. 전체 검색 결과를 점수순 또는 주제·단어·문장별로 묶어 본다.
67. 데스크톱 자료실을 목록–상세 2단 구조로 전환하고 선택을 보존한다.
68. 모바일 상세 화면에서 현재 필터의 이전·다음 자료로 이동한다.
69. 필터 전체·현재 화면 선택과 반전을 제공하고 숨은 선택 수를 표시한다.
70. 여유 목록·컴팩트 목록·카드 격자 보기를 저장한다.

## 71–80 · 게임 자율성과 플레이리스트

71. 게임을 3분·5분·10분·제한 없음 예상 시간으로 좁힌다.
72. 읽기·쓰기·듣기·말하기·암기 기술별 필터를 제공한다.
73. 추천·최근·자주 한·이름순 정렬과 로컬 실행 횟수를 제공한다.
74. 추천 게임을 오늘 또는 7일 동안 숨긴다.
75. 더 보기·덜 보기 피드백을 추천 가중치에 반영한다.
76. 깜짝 게임에 기술·시간·시간 제한 조건을 지정한다.
77. 최근 게임의 마지막 규칙을 바로 다시 실행한다.
78. 매치·시간형 게임의 개인 최고 기록을 로컬 저장한다.
79. 선택적 도전 모드에서 정확도·속도·힌트를 조합한 점수를 보여 준다.
80. 2–5개 게임을 순서대로 실행하는 개인 플레이리스트를 저장한다.

## 81–90 · 온보딩과 첫 학습

81. 시작 설정을 짧은 단계와 명확한 진행률로 나눈다.
82. 완료하지 못한 온보딩 선택을 로컬 저장하고 재시작 뒤 이어 간다.
83. 이전·나중에 하기·완료 결과와 계정 없는 샘플 학습을 설명한다.
84. 언어·목적·수준·시간·시작 방식을 마지막 단계에서 검토한다.
85. 큰 버튼·고대비·시간 제한 없음 접근성 시작 프로필을 제공한다.
86. 화면 모드와 대표 강조색을 실제 미리보기로 고른다.
87. 샘플 시작 전에 첫 문제 3개와 예상 시간을 보여 준다.
88. 목적·수준을 첫 큐·그룹·게임 추천에 반영한다.
89. 학습 요일과 쉬는 요일을 오늘 계획·알림 계산에 반영한다.
90. 홈 빠른 행동 3개를 선택하고 순서를 바꾼다.

## 91–100 · 적응형 학습과 세션 복구

91. 각 답변의 응답 시간을 기존 기록과 호환되게 저장한다.
92. 뜻·쓰기·듣기·문장·발음 숙련도를 항목별로 집계한다.
93. 오답 유형·응답 시간·기술 숙련도로 다음 문제를 고른다.
94. 적응형·균형·사용자 지정 출제와 추천 이유를 선택한다.
95. 정답을 노출하지 않는 유형·단어/문장 비율 큐 미리보기를 제공한다.
96. 10·20·30분 휴식 알림과 안전한 일시정지를 제공한다.
97. 읽기 표시를 현재 세션에서만 임시 변경한다.
98. TTS 속도를 현재 세션에서만 변경한다.
99. 입력 답안과 문장 배열의 미완성 상태를 체크포인트에 저장한다.
100. 재개 시 입력·토큰 순서·저장 시각을 복원하거나 비우고 다시 시작한다.

## 101–110 · 통계와 동기부여

104. 정확도 추세와 날짜별 표본 수를 함께 표시한다.
105. 실제 세션 시작·종료 시각으로 학습 시간 추세를 계산한다.
106. 문제 유형별 숙련도와 최근 변화를 보여 준다.
107. 여러 학습 주제의 학습량·정확도·복습량을 비교한다.
108. 어려운 항목에 오답 이유·마지막 학습일을 표시하고 바로 복습한다.

## 111–120 · 접근성·키보드·음성 피드백

111. 문제·힌트·정오답·저장·완료를 스크린리더 live region으로 안내한다.
112. 다이얼로그·시트 종료 뒤 열었던 버튼 또는 다음 입력으로 초점을 복원한다.
113. 언제든 여는 문맥별 키보드 도움말 오버레이를 제공한다.
114. 전역 단축키를 기기별로 재지정하고 충돌을 표시한다.
115. 힌트·모르겠어요·건너뛰기·일시정지 키를 재지정한다.
116. 문제·피드백·모달의 초점 순서와 최초 초점을 고정한다.
117. 반투명·블러·겹침 효과를 없애는 투명도 줄이기를 제공한다.

## 121–130 · 확장 테마 프로필

121. 라이트와 다크 모드의 강조색을 따로 저장한다.

123. 대비 검사를 통과한 사용자 지정 강조색 또는 안전 색상표를 제공한다.

125. 테마 프로필 이름 변경·복제·삭제·정렬과 손상 격리를 제공한다.
126. 시스템 산세리프·플랫폼 세리프·고정폭 글꼴을 고른다.
127. 앱 글자 크기와 별도로 문제·정답 글자 크기를 조절한다.

129. 주요 내비게이션 아이콘을 윤곽형·채움형으로 선택한다.

## 131–140 · Local-First 데이터 안전

131. SQLite·로컬 폴더·Drive·대기 작업 상태를 설명하는 데이터 건강 화면을 제공한다.
132. 마지막 정상 백업의 시각·크기·항목 수·검증 결과를 표시한다.
133. 대량 가져오기·일괄 삭제·복원 전에 자동 복구 체크포인트를 만든다.
134. 체크포인트의 원인·시각·크기를 보고 복원하거나 안전하게 삭제한다.

## 호환성과 데이터 보호

- 사용자 학습 콘텐츠와 상세 진도는 계속 Local-First 원칙을 따른다.
- 1.30 데이터는 실제 SQLite migration E2E로 1.31 형식 업그레이드와 원본 보존을
  검증하며, 손상 DB와 미래 schema는 정상 로컬 데이터를 덮기 전에 차단한다.
- 화면·학습 취향은 동기화할 수 있지만 알림, 음성, 보호 커튼 시간 등 기기 속성은
  기기 전용 저장소에 남는다.
- 구버전 정리는 1.31.0 manifest 재검증 뒤 낡은 빌드 산출물만 대상으로 한다.
  SQLite DB, Drive 데이터, 복구 체크포인트와 백업은 삭제하지 않는다.

## 네 플랫폼 전달 정책

- Windows와 Android는 Mock Mode를 끈 `REAL` 연결 빌드다.
- Android release keystore가 없으면 `google-debug-signed`로 표시하며 Play 배포본이 아니다.
- Windows 코드 서명 인증서가 없으면 설치 EXE는 기능 검증용 무서명 산출물이다.
- iOS는 Simulator용 `MOCK` ZIP이며 실제 기기용 IPA가 아니다.
- macOS는 unsigned/ad-hoc `MOCK` ZIP이며 Developer ID 서명·공증 배포본이 아니다.
- 실제 파일명, 크기, SHA-256, 실행·첫 프레임 결과와 CI 사실은 최종
  `release-manifest-1.31.0.json`에만 기록한다. 이 문서에는 미실행 결과나 임의
  해시를 기입하지 않는다.
