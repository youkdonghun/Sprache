여섯 언어

영어, 일본어, 독일어, 프랑스어, 스페인어, 중국어 간체 코스를 제공합니다.

나만의 주제

시험, 취미, 업무처럼 원하는 주제를 직접 만들고 자료를 명확한 표현–뜻 쌍으로 정리합니다.

직접 만든 자료

단어, 여러 뜻, 예문, 문장, 읽기, 태그와 출처를 앱 또는 Excel·CSV·JSON에서 관리합니다.

원하는 학습 방식

플래시카드, 뜻 선택, 직접 쓰기, 빈칸, 문장 배열, 듣고 쓰기와 발음을 지원합니다.

내 데이터는 어디에 저장되나요?

학습 자료와 상세 진도는 기기의 SQLite와 내 Google Drive 사이에서 안전하게 이어집니다. 첫 실행에서 Google 연결을 마치면 사용자가 고른 Drive 위치의 WordStudyData 폴더에 검증된 동기화 자료를 보관합니다.

  • 별도의 로컬 백업 폴더를 고를 필요 없이 Google Drive를 기본 저장 공간으로 사용합니다.
  • Drive의 숨겨진 앱 설정에는 학습 자료가 아닌 WordStudyData 폴더 포인터만 저장합니다.
  • OAuth 인증 코드는 PKCE로 Google에 직접 교환하며, 토큰은 운영체제 보안 저장소에만 둡니다.
  • 별도 Sprache 서버로 학습 자료, 계정 연결 또는 토큰을 보내지 않습니다.
  • 광고, 데이터 판매 또는 사용자 프로파일링을 하지 않습니다.
  • PDF 원본은 업로드하지 않고, 사용자가 검토해 저장한 단어와 짧은 출처 정보만 동기화합니다.
