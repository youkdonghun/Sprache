# Sprache 1.39.1

## 발음 표기 바로잡기

- 언어팩의 라틴 문자 표제어를 철자만 보고 한글 발음으로 추측하던 동작을
  없앴다. 검수된 읽기가 없는 항목은 부정확한 한글 표기를 노출하지 않고
  기기의 원어 TTS로 발음을 들려준다.
- 영어 `beef`의 읽기를 `비프`로 바로잡았다.
- 받침으로 옮길 수 없는 자음을 조용히 버리던 한글 음차 보조 로직을
  수정하고 회귀 테스트를 추가했다.

## 전체 언어팩 복원

- 모든 언어의 공통 교집합만 남기던 생성 방식을 한국어와 각 학습 언어의
  1:1 정렬 방식으로 교체했다.
- 독일어 463개, 영어 459개, 스페인어 449개, 프랑스어 458개,
  일본어 455개, 중국어 간체 469개를 제공한다. 같은 표제어에 연결된
  여러 한국어 뜻은 버리지 않고 한 단어의 허용 정답으로 합쳤다.
- 기존 축소판을 받은 사용자는 언어팩 화면에서 새 전체판으로 업데이트할
  수 있다. 같은 ID의 이전 항목은 새 출처 버전과 읽기로 정확히 교체된다.
- 일본어는 원본에서 안전하게 대응되는 가나 429개를 함께 제공한다.

## 언어팩 사용성 및 성능

- 자료 변경이 없는데도 화면 상태가 바뀔 때마다 전체 중복 분석을 다시
  실행하던 경로를 캐시해 언어팩 설치 후의 버벅임을 줄였다.
- 같은 가져오기 미리보기의 중복 판정 결과도 재사용한다.
- 언어팩 카드에 축약 수가 아닌 전체 수를 표시하고, 자료실에서는 내부
  소스 ID 같은 기술 문구를 숨겼다.
- 설치 영수증과 콘텐츠 버전을 함께 확인해 현재판/업데이트 상태를 더
  정확히 표시한다.
