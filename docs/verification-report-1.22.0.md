# Sprache 1.22.0 검증 보고서

검증일: 2026-07-30

## 구현 범위

- 버전 `1.22.0+38`
- 영어·일본어·독일어·프랑스어·스페인어·중국어의 `hangul` 읽기 스킴
- 단어·문장 편집 화면의 `한국어 발음` 입력과 언어별 예시
- 학습·플래시카드·발음·단어장 상세의 한국어 발음 우선 표시
- 일본어 가나·로마자, 중국어 병음과 한국어 발음의 동시 보존
- 내장 카탈로그의 언어별 대표 입문 단어 6개·문장 3개 이상에 한국어 발음 예시
- 간편 Excel 17열과 전체 Excel 37열의 단어·문장 및 예문 한국어 발음
- 개인 콘텐츠 Excel·CSV 27열 내보내기와 재가져오기

## 가져오기와 중복 처리

기본 열은 `korean_pronunciation`이며 `한국어_발음`, `한글_발음`, `hangul`,
`korean_reading`, `ko_pronunciation`도 허용한다. 단어 예문은
`example_pronunciation`, 여러 예문은 `example_2_pronunciation`,
`example_3_pronunciation`으로 독립 문장 항목의 한국어 발음에 연결한다.

같은 언어·유형·표현·품사의 여러 행은 기존 뜻을 지우지 않고 뜻·허용 정답·
그룹·읽기 표기를 합친다. 따라서 같은 단어에 뜻과 한국어 발음을 나누어
입력해도 한 항목으로 병합된다.

## 남은 품질 작업

- 내장 720개 전체가 아니라 언어별 대표 입문 표현부터 한국어 발음을 제공한다.
  나머지는 사용자가 편집 화면이나 Excel에서 추가할 수 있다.
- 한국어 발음은 학습 보조 표기이며 실제 음가를 완전히 대신하지 않는다.
  내장 표기는 배포 전에 원어민과 한국어 화자의 교차 감수를 반복한다.
- 1.22.0 템플릿의 Android 시스템 선택기 실측과 물리 기기 TTS·마이크 시험은
  배포 단계에서 반복한다.
