# Sprache 1.40.2

## 영어 발음 표기 재정비

- 영어 언어팩에서 가져온 한글식 발음 표기를 팩 버전과 Drive 수정 시각에
  관계없이 모두 제거한다.
- 앱 기본 영어 자료도 부정확한 한글식 발음을 표시하지 않고 실제 TTS 음성을
  발음 기준으로 사용한다.
- 과거 영어 한글 발음 사전과 기본 예시 문자열도 소스에서 삭제하고, 입력란은
  사용자가 직접 확인한 표기만 선택적으로 넣도록 안내한다.
- 앞으로 다운로드하는 영어 언어팩에 구형 한글 발음 필드가 포함되어 있어도
  가져오기 전에 제거한다.
- 사용자가 직접 만든 개인 자료의 한글 발음은 그대로 유지한다.
- 시작·Drive 병합·백업 복원에 같은 정리 규칙을 적용해 다른 기기에서 잘못된
  표기가 되살아나는 것을 막는다.

## 언어팩

- 영어 생활 핵심 어휘 팩을 `2026.09.3`으로 갱신하고 마지막 한글 발음 필드를
  제거했다.

## 검증

- 임의의 과거·현재·미래 버전과 높은 콘텐츠 버전에서도 영어 팩 발음이
  제거되는 테스트를 추가했다.
- 기본 영어 자료와 다운로드 언어팩에 한글 발음이 남지 않는 테스트를
  추가했다.
- Flutter 정적 분석과 전체 테스트, Windows·Android·Web 빌드를 배포 전에
  검증한다.
