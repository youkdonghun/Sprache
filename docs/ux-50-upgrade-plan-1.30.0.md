# Sprache 1.30.0 사용자 편의성 50개 업그레이드

## 방향

공식 제품 문서를 기준으로 Duolingo의 즉시 연습 진입, Quizlet의 빠른 입력과 대량
붙여넣기, Anki의 데이터 안전성과 사용자 정의 세션, LingQ의 문맥 안 단어 저장,
Busuu/Babbel의 짧은 복습, Memrise/Drops/Clozemaster의 게임 선택성을 비교했다.

이번 릴리스의 원칙은 다음과 같다.

- 단어를 등록할 때 화면 이동, 재입력, 정리 부담을 줄인다.
- 추천은 제공하되 게임과 퀴즈의 규칙을 사용자가 바꿀 수 있게 한다.
- 목숨 소진처럼 학습을 막는 장치는 기본값으로 사용하지 않는다.
- 단어 등록, 복습, 보상, 스트릭은 인터넷 연결 없이도 동작한다.
- 모든 변경은 Android, Windows, iOS 공통 Dart 코드에서 먼저 검증한다.

## 50개 목표

상태 표기: `[ ]` 예정, `[~]` 진행, `[x]` 구현·검증 완료.

### 명시적 문장 토큰과 대량 입력 (1–14)

1. `[x]` 문장 배열 토큰을 저장 시 자동 분절하지 않고 명시적으로 입력한다.
2. `[x]` 토큰을 칩으로 추가·삭제하는 공용 편집기를 제공한다.
3. `[x]` 사용자가 누른 경우에만 문장을 토큰 후보로 나누는 명시적 도우미를 제공한다.
4. `[x]` 토큰의 순서를 앞·뒤로 이동해 바로 교정할 수 있게 한다.
5. `[x]` 문장 배열에 필요한 최소 토큰 수와 빈 토큰을 저장 전에 검증한다.
6. `[x]` 기존 문장을 편집할 때 저장된 토큰을 그대로 보존한다.
7. `[x]` 대량 붙여넣기에 탭·쉼표·세미콜론·콜론·파이프·대시를 지원한다.
8. `[x]` 붙여넣기에서 감지한 형식을 사용자에게 표시한다.
9. `[x]` 시스템 클립보드에서 명시적으로 붙여넣는 버튼을 제공한다.
10. `[x]` 붙여넣은 원문을 한 번에 비우는 버튼을 제공한다.
11. `[x]` 가져오기 전에 앞부분 행을 표 형태로 미리 보여 준다.
12. `[x]` 잘못된 행의 줄 번호와 수정 이유를 표시한다.
13. `[x]` 동일한 표현·뜻 행은 NFKC 정규화 후 한 번만 가져온다.
14. `[x]` 100개 제한, 가져올 수 있는 수, 제외 수를 저장 전에 명확히 알린다.

17. `[x]` NFKC·공백 정리 결과가 달라지는 경우 저장 전에 안내한다.
18. `[x]` 일본어 kana/romaji, 중국어 pinyin, 한국어 읽기를 언어별 필드로 분리한다.
19. `[x]` 지원 언어의 한국어 발음 추천을 확인 후 적용할 수 있게 한다.

24. `[x]` 태그·품사·즐겨찾기·학습 우선순위를 등록과 동시에 지정한다.
25. `[x]` Windows에서 Ctrl+Enter 저장, Ctrl+Shift+Enter 연속 저장, Esc 안전 종료를 제공한다.
26. `[x]` 입력 초안을 기기 로컬에 자동 저장하고 앱 재시작 뒤 복원·삭제한다.

31. `[x]` 오늘·학습·자료실·기록·설정 어디서든 전역 빠른 추가를 연다.

### 게임 발견성과 학습 자율성 (33–49)

33. `[x]` 복습량·오답·새 자료를 근거로 한 가지 게임을 추천하고 이유를 표시한다.
34. `[x]` 숨겨져 있던 매치 스프린트를 학습 허브의 독립 게임으로 노출한다.
35. `[x]` 사용 가능한 게임 중 하나를 골라 주는 ‘깜짝 게임’을 제공한다.
36. `[x]` 게임 이름·설명·기술로 검색할 수 있게 한다.
37. `[x]` 자주 쓰는 게임을 즐겨찾기해 위에 고정한다.
38. `[x]` 사용하지 않는 게임은 숨기고 언제든 복원할 수 있게 한다.
39. `[x]` 게임별 마지막 문제 수·규칙을 기기 로컬에 기억한다.
40. `[x]` 5·10·20문제와 전체 문제 프리셋을 제공한다.
41. `[x]` 3·5·10분 시간 예산 프리셋과 예상 완료 시간을 제공한다.
42. `[x]` 편안함·기본·도전 난이도 프리셋으로 여러 규칙을 한 번에 조정한다.
43. `[x]` XP·진도에 반영하지 않는 자유 연습을 시작 전에 켜고 끈다.
44. `[x]` 학습어→뜻·뜻→학습어·혼합 출제 방향을 세션마다 고른다.
45. `[x]` 느슨함·보통·엄격 채점을 세션마다 고른다.
46. `[x]` 객관식 선택지 수를 2·4·6개 중 고른다.
47. `[x]` 타이머·힌트·자동 진행·소리·큰 버튼을 빠른 게임 규칙에서 조정한다.
48. `[x]` 문제를 감점 없이 건너뛰어 큐 끝으로 미룰 수 있게 한다.
49. `[x]` 결과에서 오답만·같은 문제·새로 섞기, 문제 수정, 다음 추천을 바로 실행한다.

## 릴리스 목표

- 앱 버전: `1.30.0+54`
- Windows와 Android는 이 PC에서 실제 빌드·설치·실행 검증한다.
- iOS 프로젝트와 공통 기능은 준비하고 macOS CI에서 시뮬레이터 빌드를 검증한다.
- 서명된 IPA는 Apple 인증서·프로비저닝과 macOS/Xcode가 있어야 생성한다.
- 새 산출물 검증 전에는 기존 설치본이나 학습 DB를 삭제하지 않는다.
- 새 설치본 검증 뒤 1.29 바이너리만 제거하고 로컬 학습 데이터는 보존한다.
