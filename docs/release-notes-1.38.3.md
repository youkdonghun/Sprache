# Sprache 1.38.3

이번 버전은 학습 시작과 Google Drive 동기화 안내를 더 단순하게 정리했습니다.

- 추천 학습의 카드와 `바로 시작` 버튼은 저장된 기본값으로 즉시 학습을 시작합니다.
- 추천 학습을 세부 조정하고 싶을 때만 별도의 설정 버튼을 사용합니다.
- 자동·백그라운드 Drive 동기화 상태와 오류는 학습 화면에 표시하지 않습니다.
- 사용자가 직접 연결하거나 동기화할 때만 진행 상태와 필요한 조치를 안내합니다.
- 다른 언어에서 진행하던 퀴즈가 현재 언어의 새 퀴즈 시작을 막지 않습니다.
- 홈과 공통 상단 영역에서 반복되던 Drive 상태 표시를 걷어내 화면을 간결하게 했습니다.

버전: `1.38.3+71`
