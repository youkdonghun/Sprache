# Sprache 1.31.0 개인화·직관성 200개 업그레이드 계획

## 제품 방향

이번 릴리스는 기존 1.30.0의 빠른 자료 등록과 자유 학습 기능을 유지하면서,
사용자가 화면과 학습 흐름을 자기 습관에 맞게 바꿀 수 있도록 확장한다.

- Babbel의 단순한 화면 모드, LingQ의 읽기 화면 사용자화, Anki의 미니멀 학습,
  Drops의 이어하기와 짧은 루틴, Memrise의 선택 가능한 추천을 참고한다.
- 기본값은 1.30.0과 동일하게 유지하여 기존 사용자의 화면과 학습 흐름을 갑자기
  바꾸지 않는다.
- 모든 선택은 로컬에 먼저 저장하고, 기존 설정 snapshot 규칙으로 안전하게 동기화한다.
- 알 수 없거나 손상된 설정은 앱을 중단하지 않고 검증된 기본값으로 복구한다.

## 참고한 공식 제품 흐름

- [Babbel 다크 모드](https://support.babbel.com/hc/en-gb/articles/17328447779732-Dark-mode):
  기기 설정을 따르거나 사용자가 직접 화면 모드를 고르는 단순한 선택 구조
- [LingQ 5.0](https://www.lingq.com/blog/introducing-lingq-5-0/):
  읽기 화면과 학습 경험을 사용자 습관에 맞게 조절하는 방향
- [Anki 환경설정](https://docs.ankiweb.net/preferences.html):
  시스템 테마, 최소 동작과 학습 옵션을 분리해 보존하는 방식
- [Drops 새 홈](https://languagedrops.com/blog/welcome-to-your-brand-new-home):
  학습 시작점을 짧고 분명하게 만들고 이어하기를 전면에 두는 방식
- [Memrise 학습 진도](https://www.memrise.com/blog/new-progress-tracking-for-language-learning):
  진도와 추천 근거를 사용자가 이해하기 쉬운 단위로 보여 주는 방식

특정 앱의 화면이나 문구를 복제하지 않고, 선택 수를 줄이는 구조·즉시 재진입·
설정의 예측 가능성 같은 원칙만 Sprache의 Local-First 모델에 맞게 재설계했다.

상태 표기: `[ ]` 예정, `[~]` 진행, `[x]` 구현·검증 완료.
